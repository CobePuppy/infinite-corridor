# ∞ 回廊 · INFINITE CORRIDOR

> 一局一廊，走廊记得你停在哪。
>
> 浏览器单页 Roguelite，Qoder 高校创造力大赛参赛作品。默认主题「抽象几何」，另备
> 「旧城 / 学科 / 武当」三套主题可在开始页切换：四套各有独立色板、背景构图与造型，
> 全部由程序化绘制生成，**零美术资源、零音频文件、零后端、零账号、零构建**。
>
> 单局 3–8 个房间 + 首领（经典射击），24 个词条分「数值 / 机制 / 协同」三层。
> **单条命通关目标 240s ± 30s（约 4 分钟）**；主模式真人计时仍待验收。
>
> **主玩法「自由回廊」（首页第一入口，M11）**：三层 × 三间 + 每层巡廊者。按 `E` 自己定起点，
> 沿真实走位画出的**闭合多边形**就是攻击范围——回到起点才兑现，沿玩家路径逆行的回扫波
> 只结算圈内敌人；伤害按**圈住的面积**分小 / 中 / 大圈，折点数决定折角圈，面积过小直接拒绝。
> 场地铺有固定布局的**常驻正负地效格**（增幅 / 滞涩）；命中触发「斯安维斯坦」凝滞
> （世界 0.30×、玩家全速 0.35s），冲锋预警里按 Shift 是**完美闪避**，连段升到 T1–T3 会垫步。
> 开局可选回扫、大剑或手炮流派，清房后只抽取所选流派的强化。
> **M13 圈型策略**：换圈型才涨连扫倍率（×1.0 → ×1.2 → ×1.4），连刷同型逐次衰减到 ×0.5；
> 小 / 中 / 大圈各给「迅捷减 CD」「续航回血」「破阵额外蓄势 + 延长凝滞」，折角圈附加圈边穿透。
> 走位时 HUD 实时显示正在画的圈型与上圈是否同型，逼玩家主动改走法而不是原地刷最小圈。
> 层末与换房自动存档，可从「从上次离开的圈接着走」续玩（存档指向下一间）。
> 旧「回廊长局」保留为首页第二入口「**经典回廊（旧版可回退）**」，原射击长局为「经典射击」，
> 单房原型仍在「试玩」区。
>
> **M8 视觉语言「深蓝测绘图 / 夜航档案」**：极深墨蓝底 + 图廓刻度 + 唯一高亮琥珀金；
> 路径雾青、危险朱红。走过的廊道画成可见通道，闭环回扫是一道逆行光带。
> 四套主题共享骨架、换材质（精密网格 / 砖纹灯晕 / 方格纸 / 墨晕山岚）与后处理强度，
> 界面与战场同步换色。**零美术资源**，全部 Canvas 2D 程序化绘制。

## 运行

本地 UI 改版快照。打开 `index.html` 进入游戏，页面和两套同帧美术见
[界面对照](docs/界面对照.html)，试跑方法与结果见 [UI 验收记录](docs/UI验收记录.md)。

**直接双击 `index.html` 即可玩**（纯静态、无构建、无依赖、无 ES module，因此 `file://` 下也能打开）。
演示、试玩与自动化验收均**不需要本地服务**；如确有需要请自行选择空闲端口并自行管理，
本项目不会启动或占用任何端口 / 后台进程。
进度（金币、已解锁词条、最佳时长）存 `localStorage`，断网可玩。

**自由回廊怎么玩（当前主模式）**：首页点 **自由回廊**，选回扫、大剑或手炮流派。按 `E` 在当前位置定起点（画面出现 ORIGIN 环）
→ 用 WASD 走出去，围出一个闭合多边形 → **回到起点**才兑现，沿刚才走过的路径**逆行**的回扫波
只结算圈内敌人。圈住的面积决定小 / 中 / 大圈伤害，折点数决定折角圈；面积过小直接拒绝并自动
重设起点。按 **Q** 或点 HUD 的武器按钮，可随时在大剑和手炮间切换。左键使用当前武器。大剑沿挥击方向依次命中，后续目标伤害递减。手炮主弹射向瞄准点，散射副弹伤害减半。**连续画同一种圈会逐次衰减，
换一种圈型才涨连扫倍率**；小 / 中 / 大圈分别给减 CD / 回血 / 破阵蓄势，折角圈让回扫波扫到圈边。
命中会触发凝滞（世界 0.30×、玩家全速 0.35s），冲锋预警里按 Shift 是完美闪避；场地铺有常驻正负地效格。
每间清场后从开局选定的流派卡池中拿一张牌，切换武器时仍使用同一卡池。手炮流派可选远射、稳射和压制，分别延长射程、收紧副弹和用主弹减速。越往后，敌人的生命、伤害和移动速度越高。每三间打一场巡廊者（护盾分相位，只认指定圈型破盾），
层末自动存档。局内存 `localStorage['corridor.free.save.v1']`，下次首页点
**从上次离开的圈接着走** 从下一间继续。
旧「回廊长局」保留为第二入口 **经典回廊（旧版可回退）**，存 `corridor.loop.save.v1`。

**武器试玩** → 选版本 A / B、大剑（重刃） / 手炮、预设 1 / 2 → **进入房间**。WASD 移动、鼠标左键攻击，
Shift 冲刺。按 Esc 后点「更换武器 / 设置」，可返回选武器。暂停内重开会沿用本次设置。 [自测记录](docs/单房自测记录.md)

开始页先选 **重刃** 或 **手炮**，再点 **试玩击飞接力**。用左键把敌人打进后排，也可以对仍在飞的敌人
补击改向。首组清完获得 1 个构筑点，选一项本武器的强化，在同一条直廊打完第二组。

选择 **试玩碰撞组合** 可用同样的武器在一间房连续迎战两拨。打飞后松开左键再按一次，试着同向补击、
借墙后侧向补击，或在箭头出现后侧击冲锋怪。飞行目标上的轨迹会提示出手方向。

开始页的 **试玩廊道回扫** 包含一间普通房和一场首领战。选好词条后，从标记廊口出发，沿一条廊去，
从另一条廊回来。回扫从返程廊道开始，沿刚走过的廊道倒着传播。试玩站位 A 的炮台在下廊，站位 B
在同一张图的上廊。走到清房后的右侧光环进入首领战，用回扫打破巡廊者的护盾。试玩结算独立于原版的
金币和解锁存档。**进入原版长局** 继续使用原有的关卡和词条。

游戏本身不需要 Node；下方的**验收脚本**需要 Node（零依赖，无需 `npm install`，无构建步骤）。

## 操作

| 输入 | 作用 |
|---|---|
| `W A S D` / 方向键 | 移动（带惯性与加减速） |
| 鼠标移动 | 瞄准 |
| 鼠标左键 / 空格 / `J` | 攻击 |
| `Shift` | 冲刺，短暂无敌 |
| `E` | 自由回廊：在当前位置定起点，回到此处兑现闭环（M11） |
| `Q` | 自由回廊：局内切换大剑 / 手炮 |
| `Esc` | 暂停 / 返回：游戏中弹出暂停面板（继续 / 重开本局 / 返回开始页）；解锁页按 Esc 直接返回 |
| `M` | 静音开关 |
| `R` / `Enter` | 结算页一键重开 |

每局 3–8 个房间 + 1 个首领。清空房间后右侧出口开启，走到出口从两个词条里选一个，
每第 3 / 6 / 9 次选择升级为**三选一**（稀有 / 史诗优先）；词条共 24 个，分数值 /
机制 / 协同三层，特定组合会解锁「共鸣」质变并在词条卡上提示。房间分
`普通 / 精英 / 事件 / 休整` 四型，首领半血切第二阶段。死亡或通关后立刻结算，
本地存档一次性补到至少 9999 金币，可在「局外解锁」购买词条，或用「重置并返还金币」重配。已解锁词条会装入「自由回廊」和「经典射击」，自由回廊续档按当前解锁更新局外词条。

**主题切换**：开始页选择器可在 `抽象几何 / 旧城 / 学科 / 武当` 四套主题间切换，
当前主题存 `corridor.theme.v1`，HUD 实时显示主题标签，`#app[data-theme]` 同步驱动界面配色。
四套主题共享「深蓝测绘图」骨架，但换的是**整幅画面的材质**：几何 = 精密等距网 + 同心圆刻度、
旧城 = 错缝砖纹 + 暖灯晕 + 雨痕、学科 = 方格纸 + 装订线 + 刻度、武当 = 墨晕山形 + 云纹；
各有独立色板、底纹、造型与后处理强度（bloom / grain / vignette / halo / shock）。
规则与数值始终不变。

## LLM 配置（M2，默认关闭）

生成器**默认关闭**。没有配置、或配置里 `enabled` 不是 `true` 时，全程走离线降级模板，
`file://` 断网可玩的行为与 M1 完全一致（HUD 右上显示「离线模板 #」）。

配置只有一份，存在 `localStorage` 的键 **`corridor.llm.v1`**，值是一个 JSON 字符串：

```json
{ "enabled": true, "endpoint": "https://your-endpoint/v1/chat/completions", "apiKey": "sk-...", "model": "your-model" }
```

### 怎么填

方式一 · DevTools Console（推荐，填完刷新页面）：

```js
localStorage.setItem('corridor.llm.v1', JSON.stringify({
  enabled: true,
  endpoint: 'https://your-endpoint/v1/chat/completions',
  apiKey: 'sk-...',
  model: 'your-model'
}));
```

方式二 · DevTools → Application → Local Storage → 新增键 `corridor.llm.v1`，粘贴上面那行 JSON。

方式三 · 代码内等价接口（写入的是同一份配置）：

```js
C.gen.configure({ enabled: true, endpoint: '...', apiKey: '...', model: '...' });
```

### 恢复默认关闭 / 关闭 LLM

```js
localStorage.removeItem('corridor.llm.v1');   // 或：
C.gen.configure({ enabled: false });
```

### 接口约定与注意

- `endpoint` 需兼容 OpenAI 风格 `POST`：`{ model, messages:[{role,content}], temperature, max_tokens, stream }`；
  响应取 `choices[0].message.content`，若不是该结构则把整段返回文本交给 `extractJson` 处理。
- 请求 `temperature: 0.7` / `max_tokens: 1400` / **超时 8000ms**（`AbortController`）；
  响应经 `extractJson` → `JSON.parse` → `schema.validate` 五条校验，任一不过即降级。
- 四类失败（未配置 / 超时 / 非法或纯文本 JSON / schema 校验失败）一律降级为 `source='fallback'`。
- **安全**：`apiKey` 明文存在本机 `localStorage`，请勿提交进仓库、写进文档或截进演示录屏；
  演示 / 评审建议保持默认关闭，用离线模板保证可复现。

## 不变量（来自提示词）

- AI **只在每局开始前调用一次**生成关卡 JSON；战斗帧循环绝不调用 LLM。
- 所有关卡数据先过 JSON Schema 校验（`additionalProperties: false`、白名单、单调 threat、
  词条对互异、数值递增）再进渲染层。
- 生成失败 / 超时 / 非法 JSON / id 越界 → 8 秒内自动降级，**绝不阻塞开局**。
- 词条效果全部走 `id` 查表，关卡 JSON 内不得出现任何效果数值。
- 不引入游戏引擎、UI 组件库、后端服务；不做多人联机、账号、支付。
