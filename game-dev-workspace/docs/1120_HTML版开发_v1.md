## 操作回执

1. 首页点「开始新局」，预览种子 `20261120` 的 15 格棋盘，再点「确认落子」开始 10 分钟探索。
2. WASD 移动，鼠标瞄准，左键普攻、右键小技能、Space 冲刺。村庄产氛围，攻击命中涨战斗值，两槽满后按 Q。陶罐可以打破，有技能球时按 V 选择。
3. 资源房按 B 建商场、建材厂或矿场。建厂后可在点亮房间按 F 花 8 金币制材。商人房按 E 可买料、强化或贷款。到村庄按 B 点灯。
4. 靠近亮门按 E，或按 Tab 打开棋盘，点选房间后选择「沿门进入」。棋盘用鼠标或方向键选房，T 确认向已连通房间传送。从出生 `(0,0)` 绕过 `(0,1) → (0,2) → (1,2) → (2,2) → (2,1) → (2,0) → (1,0)` 并清房，未探中心 `(1,1)` 会出现亲自迎战和付费自动探索的分支。亲自迎战要从相邻亮门进入。
5. 经 `(4,1)` 可进 `(5,1)` 的棋帅房，探索归零也会强制入场。死亡与击败棋帅分别触发结算，可直接重开，再从科技树查看矿石余额。Esc 暂停或关闭面板，切走页面会清空按键和鼠标输入并暂停，回来后主动继续。

## 与 Windows 灰盒的对应

- 【已定】沿用固定拓扑和 .NET 同种子流，保留冲刺、伤害、双槽、大招、建造生产、贷款、传送和棋帅参数。普通、精英与棋帅用剪影、名称、扇区、圆环和方向警戒带区分。渲染改为 Canvas，面板与 HUD 改为 HTML 控件。
- 【占位】网页合并了单角色选角与落子预览，科技树用三个只读分支保留矿石入口。建筑和掉落沿用灰盒几何表现，结算不携带局内资产。绘制按窗口尺寸与像素密度重设画布，鼠标坐标按当前 CSS 区域换算。
- 【已定】网页存档使用 `localStorage`，与 Windows 的 JSON 档案独立。每个非零矿石结算以 RunId 单独入账，重复请求保留原记录。浏览器拒绝读取或写入时，页面显示提示，未落盘的矿石留在当前页内，可重试、重开和查看会话余额。刷新或关闭页面可能丢失未写入条目。本地文件的位置或浏览器配置变化时，原存档的可见性由浏览器决定。
- 【已定】网页用 `requestAnimationFrame` 驱动 10 毫秒逻辑步。单帧最多补算 120 毫秒，失焦或隐藏时清输入、重置积算并进入暂停，恢复后从新帧起算。棋盘与交易仍消耗探索时间，预览、暂停和结果停表，Boss 战只推进战斗时钟。

## 开发检查

- 【已定】使用 Node v24.21.0 读取最终 HTML，`node --check` 通过。检查静态源码只有一段内联 classic 脚本，且没有资源 URL、远程请求 API 或 CSS 导入；页面内容安全策略禁用网络连接。
- 【已定】9 组自动断言通过，覆盖单文件约束、固定地图及 Windows 种子向量、四向围住与缺口、自探及自动分支、护甲取整和冲刺小技能、建造借贷与双槽、精确超时和坐标换算、五种敌人预警与棋帅环射 12／16／18 发，以及结算去重、存储拒绝和重试回读。胜利使用 1 HP 棋帅夹具，死亡优先单独断言。

- 【待定】真实浏览器中的 `file://` 断网打开、不同浏览器存档策略、完整胜利路线、围住双局实操及帧时由集成回归复测。
