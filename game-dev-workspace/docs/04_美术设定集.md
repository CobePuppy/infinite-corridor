# 美术设定集

版本 v1.1 · 2026-11-20 · Step 2 修订  
【已定】中国围棋与古风，红色唐刀角色一，以及镇关棋帅的武将与围棋元素。其余色板、规格和画稿方向为【占位】，交付时以可读性和玩法反馈验收。[设计基线](game_design_doc.md)

## 1. 视觉风格

【占位】采用俯视 2D 手绘，角色与房间以简洁墨线收边，石板有干笔裂纹，木构用少量顺纹，金属以窄亮边提形。地表比角色和预警更低对比度。棋盘刻线使用浅墨，淡出到房间边缘。乌木和宣纸形成底色，朱砂标主人公与强调，点缀旧铜和苍白矿石。

| 用途 | 主色 | 辅助识别 |
| --- | --- | --- |
| 棋盘与街巷 | 墨青 #283235、米灰 #C8BDA6 | 四向格、瓦檐、院墙与宽路口 |
| 角色与交互 | 朱砂 #BD392F、旧铜 #C68D4D | 红斗篷剪影、空心按键框 |
| 敌方弹道与危险 | 琥珀 #F4B24A、深墨描边 | 实线弹芯、斜纹警告区和收缩边 |
| 治疗、矿石、氛围 | 青绿 #6DC291、灰白 #DBE8E8、淡紫 #AC91D8 | 十字结、尖晶、灯穗 |

【待定】白棋围边和黑棋标出生是可选表现。灰盒先用点、边与图标，确保预览与局内地图位置一致。

## 3. 房间、棋盘与界面

- 棋盘地图用象牙底、墨线门边和房型符号。已完成房点实心，未探空心，围住加双线，封锁加交叉纹。村庄和 Boss 可见，清楚标出出生、当前位置和可达入口。传送高亮连通路线。
- 房间内用石板、木柱、拱门与瓦顶剪影。战斗路径留出移动和阅读预警的空间，破坏物采用件小而对比明确的陶罐。
- 资源采集房以木梁和建造桩标可放置处。商场显示布幡和铜钱，矿场显示白矿车，建材厂显示木料与齿轮；二级建筑加独立顶饰。
- 村庄用白墙深瓦和纸灯，建造后点灯，氛围升高由灯穗与阶段发光体现。事件界面沿用宣纸边和事件稀有度图案。
- 战斗 HUD 用浅纸题签和墨边条，真实生命和临时盾以分层轮廓及数值区分。建筑能量用灯穗、战斗能量用交刃，满值合拢到 Q。Boss 单独在上方有血条与狂暴提示。
- 科技树用三张并行棋谱，前置连线可聚焦，锁节点显示文字原因。结算用战报式布局，矿石到账和失败重试保持可见，不能用动效遮住主要动作。

## 4. 美工会话可执行清单

【占位】灰盒基准为 1920×1080。场景资产原图透明 RGBA PNG，常规角色单帧 128×128，骑兵 192×128，Boss 384×384，地块 128×128。导入以 128 PPU 为基准，1 身位等于 1 Unity 世界单位；美术渲染子节点允许缩放，Collider 尺寸读取玩法数值。棋帅半径 3 身位和刀招 2.5 身位用俯视截图校验；导入圆心或足点偏移后须复检预警与命中。角色/敌人以底部足点为枢轴，投射物中心枢轴。源件和导出保存在 assets/，导入版本随工程，非独创项记录来源与授权。

| 资产 ID | 阶段与数量 | 文件交付与核对 |
| --- | --- | --- |

每包附资产 ID、源件位置、导出版本、尺寸与轴点、动画事件、授权、状态。测试提供对照截图，画面位置与判定范围、去色后可辨识性和同屏预算按[技术栈](03_技术栈.md)验收。

## 5. 提示与验收对照

【占位】为重盔圆砸与半圆扫、骑兵冲锋、棋帅三招各交一张正视截图。标预警起点、攻击朝向及生效时刻。圆、半圆、直道与棋帅环射预警即使关闭色彩仍可区分；前摇期间不显示命中特效，真实碰撞以配置为准。Boss 两阶段区别同时用造型、HUD 状态和音效。地图的自动、自主选项都写代价或奖励趋势，Boss 卡片只给入场。HUD 的 -15 金币、1 HP、叠盾和仅一条能量满均各留一张状态图。
