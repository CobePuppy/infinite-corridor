# 《关城》美术设定集与设计资源

视觉锚点为中国围棋与古风。俯视 2D 手绘，角色与房间以简洁墨线收边，石板有干笔裂纹，木构用少量顺纹，金属以窄亮边提形。乌木和宣纸形成底色，朱砂标主人公与强调，点缀旧铜和苍白矿石。红色唐刀角色一与镇关棋帅的武将 / 围棋元素为已定，其余色板与画稿方向为【占位】，交付以可读性和玩法反馈验收。

## 第一部分 · 美术设定集

地表比角色和预警更低对比度；棋盘刻线用浅墨，淡出到房间边缘。

### 3. 房间、棋盘与界面

- **棋盘地图**：象牙底、墨线门边、房型符号。已完成房实心，未探空心，围住加双线，封锁加交叉纹；村庄与 Boss 可见，传送高亮连通路线。
- **房间内**：石板、木柱、拱门与瓦顶剪影；战斗路径留出移动与阅读预警的空间；破坏物用对比明确的陶罐。
- **建筑**：商场布幡与铜钱，矿场白矿车，建材厂木料与齿轮，村庄白墙深瓦与纸灯（建成点灯，氛围升高由灯穗体现）；二级建筑加独立顶饰。
- **HUD**：浅纸题签与墨边条；真实生命与临时盾分层轮廓区分；建筑能量用灯穗、战斗能量用交刃，满值合拢到 Q；Boss 上方单独血条与狂暴提示。
- **科技树**：三张并行棋谱，前置连线可聚焦，锁节点显示原因。结算用战报式布局，矿石到账与失败重试保持可见。
