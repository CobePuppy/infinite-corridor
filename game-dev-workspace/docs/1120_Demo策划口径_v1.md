## 本轮新增占位

- 【占位】首包交付顺序为地图可玩 → 资源与大招可用 → Boss 与结算闭环。各阶段可用简图和文字呈现操作结果，前摇范围、真实生命、临时血条和两个能量值仍须分别可读。
- 【占位】本轮桌面灰盒用实际操作记录、截图或日志记录结果，并用独立进程的帧时记录提供性能证据。玩法配置沿用 02 的现有占位值，本轮新增玩法参数为零。 [技术栈与性能口径](03_技术栈.md#4-性能与运行验证) · [美术验收提示](04_美术设定集.md#5-提示与验收对照) · [文案与回归](05_文稿与日志.md#5-交接与回归)

| 顺序 | 对应验收 | 玩家应能看到和做到的事 |
| --- | --- | --- |
| 1 | M1-A 走通一层 | 从主菜单进入停钟预览，落子后移动、冲刺、清房和传送。用固定图复现中心围住与缺口，从两局分别验证真实战斗和付费自动探索。 |
| 2 | M1-B 资源与大招 | 出生有 1 建材，清房赚金币。第一局出生建商场，买料后建村庄并攒满双槽开大。第二局出生建建材厂，清房后远程花 8 金币制材，在另一资源房建矿场。另验商人贷款、负金币恢复和同局二贷拒绝。 |
| 3 | M1-C 战斗与结算 | 五类敌人与镇关棋帅有可复现的预警。可正常进 Boss 和超时强制入场。胜负均进结算，局内资产清零，矿石重启后可读且只入账一次。记录复现步骤与性能。 |

## 固定 15 格

【占位】沿用种子 `20261120`。R 资源、N 普通、E 精英、S 商人、V 村庄、B Boss。表内相邻房间四向有门，空格表示无房。全图 15 房，其中 R 有 3 处。

| 1 | N | N | N | R | N | B |
| 0 | R（出生） | N | S | | N | |

- 【占位】横纵各取坐标 0 至 2。八个外环房均完成并接入出生连通组后，未探中心 (1,1) 才被围住。保留 (1,0) 未完成，外部仍能到达中心。资源房、商人和村庄首次进入即点亮，建造另行提交。
- 【占位】移动和传送查门边。围住判定从外接矩形外扩一格的边缘做四向洪泛，只有出生连通组的已完成房作为墙。自动探索只给符合入口条件的普通、精英房，按普通奖励结算一次。围住的 Boss 仍可自主入场并获得玩家增益，此分支用独立夹具复测。 [围住、计时与固定用例](02_玩法策划.md#8-灰盒验收用例)

## 三组关键复测

| 对应验收 | 输入与预期 |
| --- | --- |
| M1-B · 取整、贷款 | 【已定】先穿甲再算攻防，非整值向上取整。【占位】攻击 24、防御 25、固定穿甲 4，伤害为 3。若该防御同时受固定穿甲 4 与法穿 10%，有效防御为 19。零金币贷款得 1 建材、余额 −15，下一笔原始收入 20 按 80% 入账 16，余额变 1。清房金币合并一笔，商场每周期一笔。 |
| M1-B · 双能量大招 | 【占位】一条能量槽为 99/100，另一条为 100/100 时按 Q，两槽和生命均保持。双满且当前生命 40、上限 100，按 Q 后两槽归零，生命 34、临时盾 30、攻击 +20。盾基于施放前已损生命，1 HP 开启仍保留 1 HP。重复开启时再扣血、叠盾，攻击增益只刷新时长。 |
| M1-C · 超时、矿石 | 【占位】合法的 Boss 专用传送费用为 5,000 毫秒。剩 5,000 毫秒确认时只进入一次危险 Boss，探索钟停在 0，普通传送落点失效。玩家与 Boss 同一步归零按死亡结算。携 3 矿石时模拟保存失败，显示待入账；用同一 RunId 重试，随后重复确认、重进结果并重启，局外余额总共增加 3。 |

【占位】探索钟用整数毫秒，预览、暂停、Boss 与结算停探索钟，建筑产出随探索钟暂停。棋帅血量严格低于 50% 才进入狂暴，正在执行的招式按起手状态完成，下次起手切狂暴。正常入场的环射为 12／16 发，超时各加 2 发；连珠为 3／4 发。保存成功后才显示矿石到账，当前会话内须能用同一 RunId 重试。保存成功前退出后的恢复范围【待定】。 [Boss 时序](02_玩法策划.md#6-首层-boss-招式时间轴) · [存档与阶段转换](03_技术栈.md#3-核心架构)

## 部分实现如何记待验

- 【待定】验收结果逐条记录。功能缺失、仅有占位交互、只能从调试入口完成整条玩家流程，或缺少实测记录时，对应项记「待验」并列具体缺口及下一次复测动作。夹具可给边界规则提供证据，玩家流程另走一遍。已有实测且与预期不符的项目交总监判「返工」。
- 【待定】M1 整体通过需 M1-A/B/C 均有实际结果、保存失败可恢复，并记录种子、配置版本、构建 SHA、操作路径、预期与实测。性能记录补硬件和采样条件。灰盒能启动、能打一场或只走通其中一条路线时，整体验收仍记「待验」。 [项目验收方式](01_项目计划书.md#7-里程碑验收方式) · [总监验收与复测责任](07_会话分工与任务分配.md#交付与决定)
