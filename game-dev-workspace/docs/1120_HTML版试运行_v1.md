## 3. 独立 Node 自检

| 组 | 输入与实际回执 |

| 固定图 | 15 房、3 资源房。留 `(1,0)` 开口时中心 `(1,1)` 外通，闭环后围住，已点亮的相邻房传送费为 2,000 毫秒。 |

| 贷款 | 获得 1 建材，余额变 −15。拒绝负余额消费和二次贷款，原始收入 20 实入 16，余额变 1。 |

| 伤害和双槽 | 物穿样例伤害 3，保底为 1，双穿有效防御 19。任一槽只差 1 点均无法开大。双满且 40 HP 时，剩 34 HP、得 30 盾、攻击 +20，两槽清零。 |

| 胜负结算 | 同一步双方归零判负，结果保留本局 3 矿石，局内矿石清零。将棋帅置为 0 HP 后推进一步，走胜利结算并封盘。 |
