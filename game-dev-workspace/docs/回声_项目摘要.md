# 《回声》项目摘要

> 精简提取自队友四份文档（项目计划书 / 玩法策划 / 美术设定集 / Unity 工程落地方案），供快速了解。

## 项目卡

- 游戏名：回声
- 类型：第一人称 3D 动作肉鸽｜Unity
- 一句话：你不是在重开一局，是在追赶上一局的自己。

**核心机制**
- 每局把玩家输入录成一条「声轨」；死亡不是清零，是留下一条声轨。
- 下一局「回声」按声轨重放：路线、开枪、拾取一分不差。
- 玩家与回声共用一根「声音」条：开枪 / 冲刺 / 受伤扣，贴身处决才补。
- 拾取先到先得；「聆听」可看回声后三秒走向。
- 每层选一次「变调」：差拍（慢一拍）/ 分响（拾取对半分）/ 消音（本层不开枪）。
- Boss 随「重合」（本局与声轨相似度）升高而变硬；最多三道回声；无永久数值成长。
- 单局 8–12 分钟，死亡即结算。

## 玩法要点

- **流程**：进入回廊 → 每层入口三选一变调 → 房间推进（争抢固定声源）→ 聆听判断走位 → 打 Boss → 结算。
- **操作**：WASD 移动、鼠标瞄准、左键开枪、Shift 冲刺、Ctrl 滑铲、F 贴身处决、Q 聆听、E 拾取、1/2/3 变调。
- **动作优先级**：近身处决 → 滑铲 → 开枪 → 冲刺。
- **三层回廊**：每层 3–5 间房间；打完三层且带满三道回声才通关。
- **数值起点【待实测】**：每秒 60 拍；声音上限 100 格；开枪 4 格 / 发；单发伤害 40；普通敌人 100 生命；Boss 基础 360；重合 100% 时 Boss 生命 +50%。

## 美术要点

- **视觉锚点**：冷混凝土回廊 + 琥珀色应急灯；主色冷灰 `#505960`，辅色琥珀 `#D8A258`。
- **回声**：半透明人形，越早一道越淡（最近灰蓝 / 次近灰紫 / 最早中性灰），用空心圆 / 三角 / 方框区分。
- **三层回廊**：材质与灯距逐层变化（低→高、密→疏）。
- **禁区**：恐怖血腥、赛博霓虹、玩家身体入镜、回声长拖尾、完整声轨预览等。

## 工程要点

- **选型**：Unity 6.3 LTS `6000.3.28f1` + URP 17.3 + Input System 1.20.1；Windows x64、DX11、前向渲染。
- **模拟**：每秒 60 拍固定步长；同一循环推进，脚本驱动物理；一帧最多补 8 步。
- **声轨**：二进制声轨（小端）+ JSON 索引；双快照 `echoes.a/b` 存档；单轨上限 108,000 步 / 16 MiB。
- **性能门槛【待实测】**：1080p，帧时 P95 ≤ 16.7ms，单步模拟 P95 ≤ 2ms。
