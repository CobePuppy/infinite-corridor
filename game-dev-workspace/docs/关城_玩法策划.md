# 《关城》玩法策划

项目卡已定的机制直接沿用。数值以整数表示，时间用毫秒，距离以 1 身位 = 100 设计单位。

## 1. 单局流程

| 时点 | 玩家在做什么 | 屏幕上有什么 |
| --- | --- | --- |
| 主菜单 / 选角 | 选角色，预览棋盘，确认落子开钟 | 棋盘预览、出生资源房 / 村庄 / Boss 标记 |
| 探索清房 | 移动、冲刺、普攻清怪，围住未探战斗房 | 俯视角房间、敌人、弹道、HUD（血量 / 时间 / 货币 / 双能量） |
| 围住二选一 | 对已围住的战斗房选「自动探索」或「亲自迎战」 | 围住路径、二选一选项与代价 / 收益 |
| 建造 | 资源房投建商场 / 建材厂 / 矿场，村庄建造 | 建造面板、材料与位置 |
| 商人 | 买建材、买强化、高利贷 | 商人面板 |
| 首领战 | 打镇关棋帅（半血狂暴） | Boss 血条、狂暴提示 |
| 死亡 / 通关 | 结算，矿石入账，重开或返回 | 结算页（胜负 / 探索 / 建筑收益 / 剩余时间 / 矿石到账） |

## 2. 操作与界面

| 操作 | 键位 | 反馈 |
| --- | --- | --- |
| 移动 / 瞄准 | WASD / 鼠标 | 按光标朝向，斜向移动归一 |
| 冲刺 / 普攻 | Space / 左键 | 冲刺残影、冷却轮廓；普攻起手与命中 |
| 小技能 / 大招 | 右键 / Q | 前方扫击；双能量不足时提示缺哪条 |
| 建造 / 交互 | B / E | 材料与位置提示 |
| 地图 / 传送 | Tab / 点选后 T | 显示目标、可达状态与耗时；超时拒绝 |
| 返回 / 暂停 | Esc | 关闭子层或进暂停面板，明确停钟 |

## 3. 核心系统

### 3.1 棋盘与围住

- 种子确定 15 节点网格（出生资源房 + 2 资源房 + 8 普通 + 1 精英 + 1 Boss + 1 村庄 + 1 商人）。
- 「围住」：已完成房间作墙，从外边沿洪泛；未探房间无法从外边到达即进入围住候选。只为有已点亮相邻入口的战斗房提供操作。
- 二选一：**自动探索**（花金币拿普通标准奖励）或**亲自迎战**（敌人背水一战，玩家获增益、稀有掉率提升）。

### 3.2 战斗

- 伤害先算穿甲、再算攻防：攻击超有效防御为差值，否则为向上取整的攻击 × 5%。
- 普攻 / 小技能 / 大招三段；清战斗房回 15% 最大生命（角色一额外 5%）。
- 大招双能量：氛围值（来自村庄建筑）与战斗值（来自攻击命中）两槽满后按 Q。

### 3.3 经济与建筑

| 入口 / 出口 | 规则 |
| --- | --- |
| 金币 | 击杀掉落（小偷 1 / 反贼 2 / 重盔 3 / 弓手 2 / 骑兵 8）；商场产币；花在买建材（12）、攻击强化（20）、远程制材、自动探索 |
| 建材 | 出生 1；商人购买或高利贷；工厂转化。建筑各用 1，升级再用 1 |
| 商场 | 20,000ms 给 4 金币；跨层逐层衰减 |
| 建材厂 | 远程花 8 金币，25,000ms 得 1 建材 |
| 矿场 | 整局一处；每 35,000ms 给 1 矿石，上限 6；矿石实际收获才进结算 |
| 村庄 | 每层 1 处；每 5,000ms 提供氛围（20/25/30 按层） |
| 高利贷 | 每局一次：得 1 建材，金币扣为负（-15），永久金币获取 -20% |

### 3.4 时间与超时

- 单局探索 10 分钟；预览、暂停、Boss 战停钟。
- 计时到 0 强制进入更危险 Boss 战（Boss 攻击 +20%、每轮环射 +2 发），后续层带随机负面效果。

## 4. 敌人与首领

| 单位 | 生命 / 防御 / 攻击 | 关键行为 |
| --- | --- | --- |
| 小偷 | 24 / 1 / 11 | 移速 150%，匕首前刺 |
| 反贼 | 36 / 9 / 15 | 大刀挥砍，前摇 650 |
| 重盔 | 88 / 17 / 24 | 圆砸 → 半圆横扫交替，敌我不分 |
| 骑兵 | 150 / 21 / 19 | 刺击 / 横扫 / 直线冲锋，低血移速提升 |
| 弓手 | 30 / 5 / 13 | 远程直线箭，瞄准 2,000 |
| 镇关棋帅 | 600 / 25 | 近身横斩 / 环射 / 连珠；半血狂暴（环射 16 发、连珠 4 发） |

**棋帅招式**：

| 招式 | 时间轴 | 冷却 / 伤害 |
| --- | --- | --- |
| 落子·连珠 | 3 发高速弹，间隔 400 | 5,000 / 21 每发 |
| 棋盘·环射 | 蓄力 1,500 后 12 发 360° | 6,000 / 18 每发 |
| 横斩 | 扇形 250、命中晕 500（近身才选） | 4,000 / 28 |

## 5. 结算与循环

- 胜利或死亡进结算，金币 / 建材 / 道具 / 技能球清零，矿石计入局外科技树（同一 RunId 只入账一次）。
- 局外科技树：角色解锁与数值、技能养成；开局效果；事件线。M1 仅展示样式与余额。
