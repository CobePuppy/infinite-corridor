# 玩法策划

版本 v1.1 · 2026-11-20 · Step 2 修订  
依据[设计基线](game_design_doc.md)。数值以整数表示，时间用毫秒，距离以玩家一个身位为 100 个设计单位。毫秒和距离只是表示方式。

## 1. 单局流程

1. 【已定】主菜单进入选角。M1 可选角色一。预览本层形状、固定种子的出生资源房、村庄和 Boss 标记，确认落子才启动本层钟。
2. 【已定】出生赠 1 建材。探索并清怪，用金币买建材和强化。点亮房间后，沿已完成的连通房间传送。能绕路围住战斗房，选择付费或自行战斗。
3. 【已定】在资源房投建商场、建材厂、矿场，在村庄建造获得氛围值。战斗积攒第二条能量。用冲刺穿过弹幕，以普通攻击、小技能和大招打进攻窗口。
4. 【已定】本层 10 分钟。合法的 Boss 入口一直开放。进入时冻结计时并锁定剩余时间。耗尽时强制进入危险战，胜利后续层带随机负面效果。Boss 胜利锁定旧层。M1 直接结算。M2 起展示下一层预览、合计旧层收益，回复 80% 已损生命后确认进入。
5. 【已定】胜利或死亡进结算。金币、建材、道具和技能球清零，矿石计入局外。由结算页返回主菜单或重开。M1 科技树显示余额和分支预览。

## 2. 地图、围住和计时

| 条目 | 可执行口径 |
| --- | --- |
| GEO-01 网格 | 【占位】种子确定坐标、门、类型和刷怪子种子。四向相邻且有门才连通。M1 15 节点，出生资源房包含在 3 个资源房内，另 8 普通、1 精英、1 Boss、1 村庄、1 商人。M2 每层可用 1–2 事件节点替换同数普通节点 |
| GEO-02 联通 | 【占位】先建连通骨架再加环。出生至少两门。Boss 在 BFS 深度靠后的叶节点且避开出生主轴，各层存在合法步行入口。村庄与 Boss 初始标记，商人 M1 占位可见。传送沿点亮房间门边运行 |
| GEO-03 围住 | 【占位】取地图外接矩形再加一圈，从外边沿按四邻域洪泛。当前出生连通组的已完成房间作为墙，其他格子可穿过。地图内未完成房间若无法从外边到达，即进入围住候选。只为拥有已点亮相邻入口的战斗房提供操作；Boss 只可自主进入。房间完成才点亮并重新计算，进入房间时锁定该次增益。Boss 即使没有普通战斗房的操作卡，仍按同一几何结果发放自主探索增益 |
| GEO-04 二选一 | 【已定】自动探索消耗金币，取得同一种普通战斗流程的标准奖励。自主探索敌人背水一战，玩家获增益且稀有掉率提升。【占位】普通/精英自动价格 10/18；敌人攻击、生命、移速各增 20%，防御加 1；玩家攻击增 50%、防御加 5；稀有档概率增加 5 个百分点 |
| TIME-01 时间 | 【占位】手动过门约 5,000 毫秒，传送每边 2,000 毫秒；连通 Boss 的专用传送花 5,000 毫秒。预览、全局暂停、Boss 战与结算停钟。局内操作、战斗和村庄/商人交互继续计时 |
| TIME-02 超时 | 【占位】计时到 0 时清理原房交互和弹幕，强制进入更危险 Boss 房。Boss 攻击增 20%，每轮环射多 2 发。续层用种子从“金币获得少 10%”“冲刺冷却多 1,000 毫秒”取 1 项；M1 仅展示记录 |
| TIME-03 留时 | 【占位】每完整剩余 60 秒为后续层产出增 4%，例如 5 分钟为 20%。锁定的各层百分比相加。地图区块先以本层完成的房间计数，每满 3 间对本层商场和村庄加 10% |

GEO-03 正例为 3×3 区域的八个外环节点均完成，中心未探且有门。打开环上的一个正交缺口，中心可由外边到达。对角不计相邻。房间间状态分为未探索、探索中、已完成，围住是附加标记。状态只在房结算提交后变化。自动探索只允许普通/精英，事件与建筑房仍按对应交互进入【占位】。资源房、商人和村庄无战斗时，首次进房完成并点亮，建筑购买另行提交。自动结算按普通房间规则和同一房间种子计金币、道具及可破坏物常规奖励，不用围住专属加成，也不发角色的战斗结束回血或命中能量。遭遇重盔友伤导致的击杀仍计基础战利品，小技能奖励仅计该技能的最后一击。

## 4. 角色一与战斗数值

| 规则 | 执行 |
| --- | --- |
| COM-01 伤害 | 【已定】先穿甲，再算攻防。攻击超过有效防御时伤害为差值，否则为向上取整的攻击力 × 5%。物理按固定值，法术按百分点。【占位】同一攻击同时带两类穿甲时，先扣固定穿甲，防御下限 0，再对剩余防御乘剩余比例并向上取整 |
| COM-02 角色基础 | 【已定】红色唐刀、均衡，基础攻击至少 20。冲刺冷却 5,000 毫秒、无敌 1,000 毫秒。【占位】生命 100、防御 5、攻击 24、移速 500 单位/秒、攻击距离 200 单位按目标表面计 |
| COM-03 普攻与小技能 | 【占位】左键单次 450 毫秒周期，含 150 前摇、100 命中和 200 恢复；物理穿甲 4。【已定】小技能 60°、冷却 9,000 毫秒，本次每击倒一敌冷却减 1,000 毫秒并回血 1% 最大生命。【占位】伤害 180% 攻击，半径 260，250 毫秒生效，可取消普攻恢复段。有效命中每目标每次结算一次 |
| COM-04 房间与跨层回血 | 【已定】清战斗房回 15% 最大生命，角色一额外 5%，角色一村庄氛围加 15%。跨层回 80% 已损生命。【占位】同一房结算事件合并到 20% 后一次向上取整，生命上限夹紧 |
| COM-05 大招条件 | 【已定】氛围值来自建筑，战斗值由攻击积攒。【占位】两条上限和消耗各 100。命中造成伤害的攻击每目标每次给 6，村庄建成后进入可产出状态，本层已可累积，跨层继续叠加。UI 展示两条实际数值 |
| COM-06 大招效果 | 【已定】扣当前生命 15% 且至少剩 1。以已损生命生成可叠加临时血条。攻加成固定值加比例，持续 10,000 毫秒，连续开启只重置增益时间且再扣血。【占位】施放前记录已损 HP L；盾增加 ceil(50%×L)，剩余盾优先承伤，每 1,000 毫秒按盾低于最大 HP 10%、20%、30% 分别减少 4、3、2 点，达到 30% 及以上减少 1；攻击增加 8 + ceil(20%×L)，激活期间保留前次加值 |
| COM-07 连招 | 【占位】普攻起手→小技能取消恢复并试图击杀一组敌人→冲刺脱离或切入→两槽满时 Q 进入爆发→普攻/小技能输出。技能冷却下限为 0。冲刺期间禁叠冲刺，受控时禁输入攻击与冲刺 |

满血开大以施放前损失为 0 生成 0 盾。以 100 上限、40 当前生命为例，开大扣 6 变为 34，生成 30 盾，攻击加 20。1 血开大仍保留 1。重复施放仍使用新损失算盾。

## 5. 刷怪与行为树

【已定】令 L 为层数，N 为进入战斗前已探索数且每层归零。普通房普通怪为 ceil(5L + N/2)再随机减 2 到加 4；精英房普通怪为 ceil(5L + N/2)，另加 L 只精英。【占位】出生完成计入 N，普通数量下限为 1。重盔属于普通配额且每房 0–2 个。出生点、门口、玩家身边留安全区，生成失败换模板或种子，已接受的房间不重复刷。

共同优先级为 死亡→受控→完成当前招式→根据距离/冷却选动作→接近或保持射程。冷却用战斗钟，前摇锁定后才产生命中。M1 战斗配数表中的生命与攻击均为【占位】。

| 敌人 | 生命 / 防御 / 攻击 | 决策与招式 |
| --- | --- | --- |
| 小偷 | 24 / 1 / 11 | 【已定】移速为角色基础 150%，距离为角色一 50%，匕首前刺、冷却 2,000 毫秒。【占位】前摇 350，收招 400，玩家冲刺窗口内不直接补刺 |
| 反贼 | 36 / 9 / 15 | 【已定】移速 80%，距离 70%，大刀攻击。【占位】入距后 650 前摇＋挥砍，冷却 2,500 |
| 重盔 | 88 / 17 / 24、26 | 【已定】移速 40%，按圆砸→半圆横扫交替，前摇各 2,000，招间隔 1,000。圆半径 150 且敌我不分，扫距 250、击晕 500 |
| 骑兵 | 150 / 21 / 19、22、32 | 【已定】移速 120%。常用刺击 800 动作＋600 硬直；横扫同重盔范围，前摇 1,500、收招起 CD 4,000；冲锋距 ≥400 时可用，跟随瞄准 1,000 后以当前移速 150% 锁直线，宽 200，命中晕 700，疲劳 1,000，CD 8,000。血低于 30% 时移速为初始 150%，移速仅对冲锋加伤 |
| 弓手 | 30 / 5 / 13 | 【已定】射程角色一的 400%，移速 60%。射程外接近，射程内原地瞄准 2,000 后发射直线箭，箭速为角色基础移速，内置 CD 2,000。【占位】瞄准结束取最后方向，飞行中固定 |

【占位】骑兵选择时先过滤距离和冷却，再对可用刺击/横扫/冲锋权重 70/20/10 抽样。已经连续刺击 4 次时，只选已满足条件的特殊招式，若无可用招式便追击等待。发动特殊招式后清零计数。冲锋增伤取 ceil(相对初始移速超出百分点 ÷ 20)。

## 6. 首层 Boss 招式时间轴

【占位】镇关棋帅 HP 600、防御 25，碰撞半径 300，移速 50% 或狂暴 60%。开战 1,000 毫秒时进入首次招式选择；玩家近身优先横斩，其次环射，再次连珠；选择器每轮只提交一招，冷却自招式最后一个命中/发射窗口结束起算，收招 600 毫秒。可用招式为空时接近玩家且每 200 毫秒重查。

| 招式 | 从选中算起的时间轴 | 冷却 / 伤害 |
| --- | --- | --- |
| 落子·连珠 | 【已定】3 发向玩家高速弹，间隔 400，速度为角色移速 120%。【占位】方向于 t=600 锁定，t=600/1,000/1,400 发射 | 5,000 / 21 每发 |
| 棋盘·环射 | 【已定】t=0–1,500 蓄力，t=1,500 同时发 12 发，360° 等分，弹速 60% | 6,000 / 18 每发 |
| 横斩 | 【已定】t=0–1,500 前摇，t=1,500 检查扇形范围 250、命中晕 500，只在玩家靠近时选。【占位】近身距目标表面 ≤250，扇角 120° | 4,000 / 28 |

【已定】血量严格低于 50% 进入狂暴，环射 16 发，连珠 4 发。【占位】当前招式按起手快照完成，下次起手换狂暴数。连珠第 4 发在 t=1,800。近战范围从 Boss 碰撞体表面测量。普通时先解决可读性，再校准生命和伤害。

## 7. 经济、建筑与成长

| 入口 / 出口 | 【占位】起始值与规则 |
| --- | --- |
| 金币 | 小偷 1、反贼 2、重盔 3、弓手 2、骑兵 8；商场产币。花在买建材（12）、角色攻击强化（20，+8 攻击，M1 一次）、远程制材和自动探索。目标口径为建筑金币比击杀金币约 4:6，逐局记录来源后校准 |
| 建材 | 出生 1，商人购买或高利贷，工厂转化获得。建筑各用 1，升级再用 1。采集房一地一建筑；升级保持类型。建筑等级 1–2，产出周期乘 75% 并向上取整，跨层衰减减弱 |
| 商场 | 20,000 毫秒给 4 金币；离开原层后每层乘 75%，2 级改 90%。收取路径为自动入账并带 HUD 浮字 |
| 建材厂 | 远程花 8 金币，从唯一队列计 25,000 毫秒得 1 建材。跨层时每层周期乘 125%，2 级改 110%。资源不中断，Boss 暂停探索钟时也暂停产出 |
| 苍白矿场 | 整局仅一处；每 35,000 毫秒给 1 矿石，上限 6。第二、三层首次建的周期候选为 30,000、25,000。跨层不衰减；矿石实际收获才进结算 |
| 村庄 | 每层 1 处，标记可见；建造耗 1 材。每 5,000 毫秒提供 20/25/30 氛围（按来源层 1/2/3），旧层每次跨层乘 90%，再加角色一 15% 和探索加成，各层分别进同一槽。M1 用事件提示作为占位 |
| 高利贷 | 【已定】每局一次，得 1 建材，金币扣为负数，永久金币获取 -20%。【占位】结算前金币 G 变为 min(G-15,-1)，负余额不能作常规消费。金币新收入抵扣债务，金币收入按来源交易批次乘 80% 后向上取整。清房金币合并为一笔，商场每周期为一笔；极小单笔可能因取整维持原值 |
| 局外科技 | 【已定】角色解锁与角色数值、技能各自养成；开局效果含建筑、商人标记、随机和时间；事件线只显示 Boss/结局分支，实际遇到才揭示。成本递增，少数节点有跨建筑前置。M1 只展示样式与持久化余额 |

【占位】掉落按每个破坏物各档一次判定，只出一项。优先极小（特殊事件）→小（2 选 1 技能球）→中（消耗品）→常见（金币/回血）；M1 关闭特殊事件，档位权重先用 1/5/15/39/40，禁用档回归空结果。破坏物永久移除。背水一战稀有提升从常见档移到技能球档。每房奖励只提交一次。普通掉落使用固定房间子种子，权重之和为 100。

【占位】固定验收种子 20261120。四向相邻代表每对节点间有门。R 为资源房，N 为普通，E 为精英，S 为商人，V 为村庄，B 为 Boss。

| 坐标 y | 从左到右的 x 坐标与房型 |
| --- | --- |
| 2 | 0 R、1 N、2 E、3 N、4 V |
| 1 | 0 N、1 N、2 N、3 R、4 N、5 B |
| 0 | 0 R（出生）、1 N、2 S、4 N |

| 对应验收 | 输入和预期 |
| --- | --- |
| M1-A / 地图 | 预览停钟。清完 x、y 均在 0–2 范围的八个外环房，中心才围住；留 (1,0) 未清时中心可从外部洪泛到达。重跑出口边界、对角、隔断房和围住 Boss 夹具。围住 Boss 自主进门得玩家增益且仍可入场，自动探索入口隐藏。固定图若需复现自探和自动两路，从两局到达同一中心 |
| M1-B / 经济 | 路线一在出生建商场、以清怪或商场收益买料，进村庄后建造，测试双能量。路线二在出生建建材厂，先清房，远程消耗 8 金币，矿场建在另一资源房。用零余额商人夹具借一次得 1 建材及 -15 金币；入账原始 20 后得 16，余额变 1；同局二次贷款拒绝 |

【占位】权威时钟以整数毫秒推进。对建造后的周期，M2 按原层建筑基准周期 × 等级周期系数 × 适用的跨层周期系数 ÷ (1+当前累计留时增益) 后向上取整。每周期产量按原层基数 × 适用的产量衰减 × 探索/角色加成后取整。矿场跨层衰减系数均为 100%，只受建造层、等级和留时增益影响。一次转层给源时钟和余额统一提交快照。

【占位】M1 用一个回血消耗品和一次技能球选择验证掉落接口。消耗品拾取后即回 10 HP；技能球拾取后二选一，本局攻击 +2 或最大 HP +10 并同步回 10 HP，同一球只应用一次。不生成专属事件或额外词条。清房与碰撞伤害均只能从同一有效事件消费一次；受控和无敌时由状态机先裁定是否命中。
