# 《关城》工程落地方案

适用范围为本地单人游戏。项目采用**双形态**落地：C# Windows 灰盒（.NET 9 + WinForms）与 HTML 单文件试玩版（Canvas 2D），共用同一套规则与数值口径。

## 1. 选型与形态

| 项目 | 选型与理由 |
| --- | --- |
| C# 灰盒 | .NET SDK 9.0.301、Windows Desktop 9.0.6、WinForms + GDI+，**无第三方库**；`dotnet build` 直接出 exe |
| HTML 试玩版 | 单文件 `index.html`（HTML + CSS + classic JS 内联），Canvas 2D 渲染，`requestAnimationFrame` 驱动 10ms 逻辑步，单帧最多补算 120ms |
| 存档 | HTML 用 `localStorage`；C# 用 JSON 档案 `src/Demo/.local/player/profile.json` |
| 测试 | C# `Checks.cs` 自检 + smoke；HTML 用 Node 语法检查 + 自动断言（Node 仅用于开发复核，运行时零依赖） |

源设计主推 Unity/C#，灰盒阶段以原生 .NET 快速验证规则，Unity 保留为正式候选【待定】。

## 2. 核心系统实现

| 系统 | 实现口径 |
| --- | --- |
| 地图与围住 | `RunSeed` 确定布局；图节点以 RoomId / 网格坐标 / 房型 / 门集合 / 房间状态保存。独立 RNG 子流生成布局 / 刷怪 / 掉落。围住用网格洪泛：已完成房间作墙，未探房无法从外边到达即进入围住候选 |
| 时钟 | 探索钟管计时与建筑推进，战斗钟管弹幕 / 状态 / 技能；全局暂停冻结两者，Boss 战只跑战斗钟 |
| 战斗 | `DamageResolver` 接收攻击快照、防御、两类穿甲、命中规则，返回整数伤害 / 盾吸收 / 剩余 HP / 控制状态。技能状态机驱动前摇 / 生效 / 冷却；弹幕对象池按弹族预热，高速弹用扫掠判定 |
| 经济 | `Wallet` 统一处理带原因的资源事务；`RunId+RoomId` 标记建筑位；产出 / 扣费 / 升级 / 刷新作为一次提交 |
| 存档 | 结算把矿石与已应用 `RunId` 写入同一版本档案；写临时文件 → 验证 → 替换并保留备份，失败显式可重试；读取按版本迁移 |

## 4. 存档与失效处理

- **HTML**：矿石以 `RunId` 单独入账、重复请求保留原记录；浏览器拒绝读写时页面提示，未落盘矿石留当前页可重试。刷新或关闭可能丢失未写入条目。
- **C#**：结算把矿石余额与已应用 `RunId` 一次写入；失败可在结算页重试。档案损坏时阻止继续入账以保留去重记录。
- 局内状态独立内存，结算才落盘；存档失败不宣称矿石到账。

## 5. 性能与验收

| 项目 | 目标【占位】 |
| --- | --- |
| 运行环境 | Windows x64、1920×1080，目标 60 FPS |
| 同屏预算 | 32 敌人、384 有效弹体、64 视觉特效、120 DrawCall |
| 帧时门槛 | 帧时 P95 ≤ 17ms、有效弹缺失 0（灰盒实测短程 P95 28ms，仅供参考） |
| 回归 | 固定种子复现连珠 / 环射 / 狂暴与弹量压力；EditMode 核地图 / 围住 / 伤害 / 事务 / 存档迁移，PlayMode 核键位 / 房间切换 / 强制 Boss / 双能量 / 对象池 |

> HTML 版回归：单文件约束、固定地图种子向量、四向围住、伤害取整、建造借贷、超时与坐标换算、结算去重、存储拒绝重试均已通过（见 `1121_WebDemo优化_v1.md`）。真实浏览器的断网打开、完整胜利路线、不同浏览器存档策略仍待集成复测。
