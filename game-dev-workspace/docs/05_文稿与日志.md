版本 v1.1 · 2026-11-20 · Step 2 修订  
叙事、台词和事件文字为【占位】。变量示例用 ASCII 花括号，显示文字用简体中文。窗口状态按[玩法策划](02_玩法策划.md)，素材位置按[美术设定集](04_美术设定集.md)。

## 1. 世界观与语气

【占位】旧关城建在一方古棋盘上。驿道是盘上的线，村火是人间的灯。自镇关棋帅封了出城的门，荒兵便沿盘巡行，把散在街巷里的人逼成了死棋。行人携一柄红穗唐刀入关，能夺回一条街，也能把夺回的地变作市坊、矿场和灯火。棋帅下一子，关城便收紧一分。他要在这一局里走到关门，给身后的人留一口气。

用短句、具体物件、克制的武侠口吻。菜单与提示优先明说动作和结果。留悬念给世界观和事件。项目游戏名、事件线具体结局【待定】。

## 4. 命名规范

- 文档和用户可见文本使用简体中文。核心文档按本次指定文件名。后续独立记录按 日期_主题_版本 命名，引用时带版本。
- C# 类型、公共成员用英文 PascalCase，参数、局部变量用 camelCase，私有字段用 _camelCase。文件名与主类型一致，如 DamageResolver.cs。配置 ID 稳定且小写，如 enemy.heavy。
- 资源使用英文 snake_case 和类型前缀。例 plr_swordsman_slash_e_001.png、boss_gate_marshal_ring.png、ui_hud_ore.png。方向用 n/e/s/w，帧序号自 001 起，源件版本用 v01，导入名保持稳定。
- Git 分支用 feat/m1-01-map、fix/m1-08-save。提交用 type(scope): 简体中文动作描述，例如 feat(map): 增加围住判定。说明范围、测试证据和关联里程碑。合并、推送和发布按项目授权。

## 5. 交接与回归

【占位】按同一构建验证四态。仅战斗能量满时大招提示“氛围值”。商人贷款后余额以负数显示。传送正好耗尽时间时显示警告，确认只触发一次强制进 Boss。存档失败后显示待入账，重试成功后再替换为胜利/死亡结果。每项记录文案 Key、实际变量、截图和构建 SHA。
