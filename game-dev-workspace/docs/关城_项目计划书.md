# 《关城》项目计划书

## 项目卡

游戏名：关城（项目名原为【待定】，HTML 试玩版定为「关城」）
类型：单机单人俯视角 2D 弹幕射击肉鸽｜技术：原生 HTML + Canvas 2D（试玩版）/ C# .NET（灰盒）
一句话：提唐刀在棋盘关城中开路，围出机会，用沿途建起的建筑为迎战棋帅备战。

核心机制
- 围棋式「围住」：点亮房间围住未探战斗房，二选一——付费自动探索（快速拿常规奖励）或亲自迎战（争稀有掉落）。
- 单局 10 分钟探索时限；超时强制进入更危险的 Boss 战，后续层带随机负面效果。
- 唐刀战斗：普攻 / 小技能（60° 扫击）/ 双能量大招（氛围值 + 战斗值双槽满后开大）。
- 经济：金币、建材两种局内资源；商场 / 建材厂 / 矿场 / 村庄四类建筑；高利贷。
- 5 种敌人（小偷 / 反贼 / 重盔 / 骑兵 / 弓手）+ 镇关棋帅 Boss（半血狂暴）。
- 局外科技树以矿石持久化；每局结算矿石入账，同一局只入账一次。
- 固定种子 `20261120`、15 节点网格地图；灰盒 + HTML 双形态，断网可玩。

约束
- 数值一律向上取整；伤害先算穿甲、再算攻防。
- 时间用毫秒、距离用「身位」（1 身位 = 100 设计单位）。
- 设计基线以 `game_design_doc.md` 为准，改动设计需先同步该文档。

## 定位

单机单人俯视角 2D 弹幕射击肉鸽，中国围棋与古风主题。核心卖点是「围住」带来的二选一抉择（付费快速 vs 亲历风险），以及经济建筑与战斗资源（金币 / 建材 / 矿石）对同一份建材的争夺。评委应能在一次短演示中看懂「围住一次、建成一处、打到 Boss」的因果链。目标玩家是核心动作与肉鸽玩家。

## 样板层验收【建议】

固定种子与灰盒。首玩者走完「预览 → 移动 → 清房 → 围住 → 亲自 / 自动探索 → 建成一处 → 打到 Boss」的完整链路。

- **围住成立**：清完外环八房后中心才围住；留一个正交缺口时中心可从外部到达。
- **经济闭合**：两局分别走「商场起手」与「建材厂起手」，覆盖买料、贷款、负金币恢复、早建矿场。
- **战斗可读**：五类敌人与棋帅招式有可复现预警；胜负均进结算，矿石重启可读且只入账一次。
