# 游戏企划与设计总结（Demo 版 v1）

> 本文件为"俯视角 2D 弹幕射击肉鸽"的玩法与系统设计总结，整理成 AI（Codex/GPT）易于理解并执行的结构化描述。
> 约定：文中标注【已定】为已锁定口径；【占位】为 demo 临时数值，正式阶段再调；【待定】为留白项。

---

## 一、游戏概述

| 项目 | 内容 |
|---|---|
| 类型 | 俯视角 2D 弹幕射击肉鸽（单机、单人） |
| 核心玩法 | 棋类玩法（围棋） + 单局内「建造 + 自动采集」 |
| 关卡结构 | 单局 3 个大层级，每层约 15 个小房间，网格状地图 |
| 美术风格 | 中国围棋 + 古风（细节【待定】） |
| 参考作品 | 《元气骑士》（关卡设计）、《梦之形》（俯视角操作）、《死亡细胞》（2 选 1 道具） |
| 用途 | 独立小游戏，参赛用 |

**围棋视觉表现**（【待定】，仅作表现手法）：白棋围出可探索区域边界；黑棋落子标记玩家重生点。当前阶段固定出生点，不深究此美术细节。

---

## 二、核心玩法循环

```
探索房间 → 清怪赚金币 → 建造建筑（自动采集）→ 强化/升级 → 挑战 Boss → 进入下一层
```

- 金币：局内货币，**不可带出**，清怪掉落（数量按怪物威胁等级）。
- 苍白矿石：局外货币，**可带出**，用于科技树养成。
- 建材：建造资源（核心）。

---

## 三、地图与关卡系统

- 地图由**单个房间作为节点**，类似围棋棋盘的点，组成**网格状**地图。
- 「围住」判定：参考围棋「气」的概念（具体算法【待定】，需定义"某未探索房间的所有相邻房间均已探索"等连通性规则）。
- 单局 3 大层，每层约 15 个小房间，房间较为宽敞。
- 完成房间后地图点亮；**联通的房间之间可随意传送**。

---

## 四、房间系统

### 4.1 房间类型

| 房间 | 说明 |
|---|---|
| 战斗房 | 分普通 / 精英 / Boss 三类，杀怪掉金币 |
| 事件房 | 内容【待定】 |
| 商人房 | 购买建材、刷新商品、升级 |
| 资源采集房 | **核心机制**，每层最多 3 个，可升级 |
| 村庄房 | 提供「氛围值」，每层仅 1 个，初始即标记 |

### 4.2 资源采集房（消耗建材建造，核心）

| 建筑 | 功能 | 备注 |
|---|---|---|
| 商场 | 每隔一段时间产出金币 | 跨层后产出降低 |
| 苍白矿石矿场 | 产出苍白矿石（局外货币） | **整局 3 层仅能建 1 个**；产出速度慢；有产出上限；产出效率按所在层级计算，跨层不衰减 |
| 建材厂 | 远程消耗金币，一段时间后产出建材 | 建造后远程使用 |

- 所有资源采集房可再次消耗建材升级至更高等级（等级越高产出越快，跨层降低效果被弱化）。

### 4.3 村庄房

- 跨层提供【氛围值】（用于大招的建筑能量）。
- 每层仅 1 个，初始位置标记在地图上。
- 首次建造后必定触发一个事件（事件有稀有度，具体内容【待定】）。
- 各层村庄房**独立生效且叠加**，进入新层后上一层的效果小幅衰减。
- 层级越高，村庄房效果越强。

### 4.4 Boss 房

- 游戏开始时即标记；刷新点不堵玩家前进方向、尽量远离玩家。
- **始终可进**；被围住时进房同样获得强力 buff，但**不可消耗金币自动探索**。
- Boss 房内计时暂停；进入 Boss 房瞬间锁定本层剩余时间。
- 完成 Boss 房后不可再探索本层。

### 4.5 探索机制（围棋「围住」）

当联通的房间像围棋一样围住未探索房间时，玩家二选一：

1. **自动探索**：消耗金币，自动获得该房间所有奖励（与普通房间相同）。
2. **自主探索**：进入房间，被围敌人进入【背水一战】模式（各项属性提升）；我方获得强力 buff；稀有技能球/消耗道具掉落概率提升。

- 探索区块越多，商场与村庄房效果越强。

## 五、经济与资源系统

### 5.1 货币

| 货币 | 归属 | 获取 | 用途 |
|---|---|---|---|
| 金币 | 局内 | 清怪、商场产出 | 升级、购买、自动探索 |
| 苍白矿石 | 局外 | 矿场产出 | 科技树养成、商人矿石商品（后期） |
| 建材 | 局内 | 初始赠送、商人购买、建材厂 | 建造建筑 |

### 5.2 经济冷启动

- 玩家出生必定在资源采集房，并获得一个初始建材。
- 商人房可购买建材（商人房科技树分支可升级为"初期即标记在地图"）。
- **高利贷**：商人处贷款，每局仅 1 次，获得 1 个建材，金币扣为**负数**；施加永久 debuff「金币获取 -20%」，不可清除；金币可通过后续攒钱**逐步回到正常（正）值**。

### 5.3 经济产出占比（目标）

- 建筑产出金币 : 清怪金币 ≈ 4 : 6。

## 六、探索与时间机制

- 每层最大探索时间 **10 分钟**（合理区间 7-10 分钟）。
- 传送消耗探索时间（有折扣，例：手动走 5s → 传送 2s）。
- 进入新层级时，先以俯视视角查看地图形状与出生点；**点击进入地图前时间暂停**，供玩家规划路线。
- 与 Boss 房连通后，可消耗固定时间直接传送到 Boss 房；Boss 房内计时暂停。
- 本层剩余探索时间越多 → 下一层资源产出效率越高（永久可叠加增益；示例：剩余 5 分钟 → 产出效率 +20%，具体数值【待调】）。
- 强制超时：探索时间耗尽 → 进入更危险的 Boss 战；胜利可进入下一层，但后续随机获得一个负面 buff。

## 七、战斗系统（伤害计算）

### 7.1 防御与伤害【已定】

- **直接加减**：伤害 = 攻击力 - 防御力。
- **保底**：穿甲结算后若 攻击力 ≤ 防御力，造成 攻击力 × 5% 的保底伤害。
- **结算顺序**：先算穿甲 → 再算攻防。
- **穿甲分两类**：
  - 物理穿甲 = 固定数值无视防御（如「无视 2 点防御」），克制低防。
  - 法术穿甲 = 百分比无视防御（如「无视 10% 防御」），克制高防。
- **所有数值向上取整，避免小数**。

## 八、角色系统

### 8.1 角色通用框架【已定】

每个角色拥有：
1. 冲刺（带无敌帧，CD 因角色而异，敏捷型更短）
2. 战斗被动天赋
3. 建造被动天赋
4. 主动技能
5. 大招（**双能量条**：建筑能量【氛围值】 + 战斗能量【攻击积攒】）

- 角色间基础数值与移动速度有差异（后期补全）。

### 8.2 角色一（唯一已设计，新手向）【已定】

| 项目 | 设定 |
|---|---|
| 设定 | 围棋 + 古风，通体红色，武器唐刀 |
| 定位 | 均衡型"小六边形"（攻击/防御/生命/移速/攻击距离均均衡） |
| 基础攻击力 | ≥ 20（保证破防） |
| 冲刺 | CD 5s，无敌帧 1s |
| 战斗被动 | 战斗房结束后额外恢复 5% 最大生命值 |
| 建造被动 | 村庄房「氛围值」+15% |
| 小技能 | CD 9s；向前方 60° 扇形快速斩击（伤害=当前攻击力×倍率）；每击倒 1 名敌人 → 小技能 CD -1s 且恢复 1% 最大生命值 |
| 大招 | 见下方 |

**大招（最终版）**：
- 开启代价：立即扣除当前 15% 生命值，**不致死**（最低保留 1 点）。
- 暂时血条：基于「已损失生命值」生成（损失越多血条越多，满血开大血条≈0）；可叠加到上一次血条上；随时间自然流失，**血条越长流失越慢**，达到 30% 最大生命值时流失速度封顶（最慢）。
- 攻击力加成：固定值 + 已损失生命值 × 比例，持续 10s，**不可叠加**；持续期间再次开启只重置 buff 时间，但仍会再扣一次血。
- 定位：残血搏命型爆发（后续数值可加封顶系数温和化）。

## 九、敌人系统

### 9.1 刷怪公式【已定】（采用方案 B）

- **普通战斗房**：普通小怪数 = 层数 × 5 + 本层已探索房间数 / 2（向上取整），再浮动 -2 ~ +4。
- **精英战斗房**：普通小怪数 = 层数 × 5 + 本层已探索房间数 / 2；精英怪数 = 层数 × 1。
- 本层已探索房间数每层重置。

### 9.2 近战小怪

| 小怪 | 定位 | 血量 | 防御 | 移速上限 | 攻击距离 | 攻击方式 |
|---|---|---|---|---|---|---|
| 小偷 | 炮灰 | 很低 | 0-2 | 玩家基础移速 150% | 角色一 50% | 匕首前刺，CD 2s；不会无缝抓玩家后摇 |
| 反贼 | 常规 | 小偷 150% | 8-10 | 玩家基础移速 80% | 角色一 70% | 大刀，伤害略高于小偷 |
| 重盔 | 坦克 | 中高 | 15-18 | 玩家基础移速 40% | 范围 | 每房 0-2 个；长柄金瓜；两招轮流、间隔 1s：①圆形范围(1.5 身位，前摇 2s，**敌我不分**)②半圆横扫(2.5 身位，前摇 2s，命中眩晕 0.5s) |

### 9.3 近战精英【骑兵】（一层精英）

| 项目 | 设定 |
|---|---|
| 移速 | 角色一基础移速 120% |
| 防御 | 20-22 |
| 血量 | 较高 |
| 武器 | 长枪 |

**招式**：
1. 刺击（平A）：窄范围，伤害中等，触发概率最高；完整周期 1.4s（0.8s 动作 + 0.6s 硬直）；**至少第 4 次刺击后强制切换**为横扫/冲刺；横扫（CD 结束）或冲刺（满足距离+CD 结束）随时可概率触发，触发后重置刺击计数。
2. 横扫：范围同重盔，伤害略低于重盔横扫；前摇 1.5s；内置 CD 4s（结束后起算）。
3. 冲锋：1s 跟随锁定玩家方位 → 以当前移速 150% 直线冲锋（方向不变）；命中 → 高伤 + 眩晕 0.7s；宽度 2 身位；距离 <4 身位不使用；冲锋后 1s 疲劳；内置 CD 8s。

**被动**：
- 血量 <30% → 移速升至初始 150%。
- 移速转伤：仅应用于冲锋，系数偏低。

### 9.4 远程小怪【弓手】

| 项目 | 设定 |
|---|---|
| 攻击距离 | 角色攻击距离 400% |
| 瞄准前摇 | 2s（瞄准时不移动） |
| 移速 | 角色基础移速 60% |
| 箭矢 | 直线飞行、不改变路径；弹速 = 角色基础移速 100% |
| 防御 | 4-6 |
| 攻击 CD | 内置 2s |

## 十、Boss 样板【镇关棋帅】（一层，古风武将 + 围棋元素）

> 数值均为 demo 占位，向上取整，待与角色一数值对齐后调整。

| 项目 | 数值（占位） |
|---|---|
| 生命值 | 600 |
| 防御力 | 25 |
| 移速 | 角色基础移速 50%（狂暴 60%） |
| 体型 | 大（碰撞半径约 3 个玩家身位） |

**招式**：
1. 【落子·连珠】：向玩家方向连射 3 发高速弹，间隔 0.4s；弹速 = 角色移速 120%；单发伤害中等；内置 CD 5s。
2. 【棋盘·环射】：360° 环射 12 发慢速弹（弹速 = 角色移速 60%）；前摇 1.5s；内置 CD 6s。
3. 【横斩】：扇形横扫，范围 2.5 身位；前摇 1.5s；命中眩晕 0.5s；内置 CD 4s；仅玩家靠近时触发。

**狂暴阶段（血量 < 50%）**：环射 12 → 16 发、连珠 3 → 4 发、移速 50% → 60%。

## 十一、科技树系统（地图一）

**三大分支（并行面板）**：

1. **角色**：解锁角色 / 角色基础数值 / 角色技能升级。三者相互独立：每个角色需单独消耗科技点解锁，解锁后分别养成。
2. **开局效果**：开局增益、开局自带选项（点数成本偏高）、建筑效果（商场 / 建材厂 / 矿场 / 村庄 / 商人）、地图中概率触发效果、局内时间效果。
3. **局内事件线**：解锁新事件（解锁时只标注所属 Boss/结局分支，不展示具体效果；玩家实际遇到时才揭示）。

**加点规则**：
- 各建筑效果大体独立加点；小部分科技点有「其他建筑的前置要求」（交叉前置），用于鼓励多分支并进；带前置的科技点不影响同分支正常养成。
- 科技点越往后升级所需苍白矿石越多。
- 当前为地图一专属科技树，未来可能新增其他地图及专属科技树。

## 十二、破坏物与掉落

- 所有房间放置少量**不可恢复**的破坏物。
- 掉落概率（分层判定）：
  - 大概率：金币
  - 大概率：回血手段
  - 中概率：局内消耗品道具
  - 小概率：局内加成道具（可掉落 2 选 1 技能球，参考《死亡细胞》）
  - 极小概率：特殊事件（可能影响结局 Boss 走向 → 多结局）
- 商人房破坏特殊事件：可能判定为损坏商品 → 与商人作战，或后续购买/升级涨价（后期补全）。

---

## 十三、死亡与局外养成

- 死亡后：本局获得的所有道具、技能球、金币**清零**；苍白矿石**可带出局外**用于科技树养成。
- 回血机制：
  - 每个战斗房结算时恢复 15% 最大生命值（角色一的战斗被动额外 +5%）。
  - 进入新层级时恢复 80% 已损失生命值。
  - 事件回血、技能球回血、角色技能回血。
