# WebDemo 优化与验收

2026-11-21 · v1 · 关城 HTML 试玩版

【已定】入口为 [HTML 试玩文件](../src/WebDemo/index.html)。本轮采用用户确认的 20 房固定棋盘和 13 分钟上限，以 [设计基线](game_design_doc.md) 第十七节为准。HTML、CSS、JavaScript 和生成式音效都在同一文件内。

## P0

| 项目 | 改动 | 验证 |
| --- | --- | --- |
| 音效 | GameAudio 接收 12 类动作事件，顶部音量控制。 | 检查事件、音色映射和音量边界。实际听感【待定】。 |
| 战斗反馈 | CombatEffects 负责受击震动、伤害数值、击杀粒子、冲刺残影和弹幕命中。 | 粒子池保持 144 个槽位，粒子到期和换房后回收。画面观感【待定】。 |
| 被动天赋 | HEROES 统一配置 5% 清房加成和 15% 村庄氛围加成。 | 清房由基础与被动合计回血 20%。首层基础村庄每轮 23 氛围。 |
| 村庄事件 | VILLAGE_EVENTS 包含四种稀有度结果，首次建成村庄展示事件，可返回再领。 | 抽取覆盖四档边界，升级保留待领事件，结算按一次领取。 |
| 局内物品 | 清风符、回春散、焰心丸和铜护符。C 看背包，1、2、3 快捷使用。 | 空场不耗清风符，定时回血分 5 次，临时攻击刷新时长，铜护符按局去重。 |
| 商人刷新 | 8 金币起步，每次增加 4。刷新次数和点亮房间数影响货物等级。 | 缺金币不换货，售出商品限制本次购买，原固定攻击强化和高利贷可用。 |

本轮替换的稀有事件、消耗品数值、弹幕配置和商人词条均为【占位】。统计从本轮版本结算的对局开始，矿石余额沿用既有浏览器存档。续局可保存一个当前对局，矿石、设置、续局和累计数据按浏览器存储。
