2026-11-20 · v1 · Step 4 · M1-DEV

【已定】首个可玩灰盒已生成。Windows x64 Release 构建成功，8 组规则自检通过，真实 WinForms 窗体已从菜单走到死亡结算并重开。M1 集成验收仍待完成。

## 交付与运行

- 【已定】工程在 `src/Demo/`。`Rules.cs` 管棋盘、钱包和整数计算，`Arena.cs` 管战斗，`Run.cs` 管局、建造与结算，`ProfileStore.cs` 管矿石档案。`GameWindow.cs` 和 `GameWindow.Drawing.cs` 管输入和绘制，`Checks.cs` 留存自动复测。界面读取 `assets/demo/palette.json`，色板缺失或无效时使用内置颜色。
- 【已定】使用本机 .NET SDK 9.0.301、Windows Desktop 9.0.6、WinForms/GDI+，没有第三方库。Unity 保留为正式候选。以下命令在项目根目录运行。

```powershell
$env:DOTNET_CLI_TELEMETRY_OPTOUT = '1'
$env:DOTNET_GENERATE_ASPNET_CERTIFICATE = 'false'
dotnet build src/Demo -c Release
.\src\Demo\bin\Release\net9.0-windows\Demo.exe
dotnet src/Demo/bin/Release/net9.0-windows/Demo.dll --self-test
dotnet src/Demo/bin/Release/net9.0-windows/Demo.dll --smoke-test
```

- 【已定】试玩键位为 WASD、鼠标瞄准、左键普攻、右键小技能、Space 冲刺、Q 大招，E 过门或交互，B 建造，F 远程制材，V 选择技能球。Tab 打开棋盘，选点后点击通行或用 T 确认传送。Esc 可关闭当前面板，或在房间内暂停。探索期间操作普通面板仍耗时。
- 【占位】地图提供一条交互捷径。当前房间点亮后，可在面板点选相邻房并花 5 秒过门，也能走到实体门旁按 E。固定种子为 `20261120`，一层 15 房。村庄首次建成显示占位提示，科技树可查看矿石余额与锁定分支。
- 【已定】常规档案位于 `src/Demo/.local/player/profile.json`，自检和窗体试跑分别在 `.local/checks/rules-*` 与 `.local/checks/smoke-*` 建隔离档。项目内 `.gitignore` 排除 `bin/`、`obj/` 和 `.local/`。结算把矿石余额与已应用的 RunId 一次写入，失败时可在当前结算页重试。
