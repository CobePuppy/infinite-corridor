## 2. 固定种子与两局路线

【占位】固定种子 `20261120`，15 间房。四向相邻节点有门，空格表示无房。R 为资源房，N 为普通房，E 为精英房，S 为商人房，V 为村庄，B 为 Boss。

| y / x | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 2 | R | N | E | N | V | |
| 1 | N | N（中心） | N | R | N | B |
| 0 | R（出生） | N | S | | N | |

1. 两局都走出生点 `(0,0) → (0,1) → (0,2) → (1,2) → (2,2) → (2,1) → (2,0)`。经过战斗房要清完，留 `(1,0)` 未完成时先查围住反例，再走 `(2,0) → (1,0)` 闭环。中心 `(1,1)` 在选探索前保持未进。随后可经 `(2,1) → (3,1) → (4,1)` 走到 Boss 的合法入口，或经 `(4,1) → (4,2)` 进村。
2. 第一局在出生建商场，清怪或等商场凑钱，经商人买建材。闭环后把至少 10 金币留给中心的自动探索，进村建造并完成双槽和正常 Boss 路线。保留本局用到的入口、房间和账目。
3. 第二局在出生建建材厂，攒够 8 金币远程制材，在资源房 `(3,1)` 建矿场。闭环后亲自挑战中心。留够探索时间等矿场实收 3 矿石，走一次胜利结算。另开同种子独立局或使用测试入口覆盖死亡、超时和存档失败。
