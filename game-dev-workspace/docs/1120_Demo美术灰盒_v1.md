# M1-ART · Demo 美术灰盒

2026-11-20 · v1 · Step 4

【已定】本轮目标是 C# WinForms Windows 灰盒。验收对应 M1-A、M1-B、M1-C。玩法沿用[设计基线](game_design_doc.md)和[玩法策划](02_玩法策划.md)，造型参考[美术设定集](04_美术设定集.md)。以下形状、纹样和色值为【占位】。

## 1. 色板与绘制接口

【已定】资源为 [palette.json](../assets/demo/palette.json)。文件使用 UTF-8，根节点是单层 JSON 对象，13 个固定小写键的值均为不透明 `#RRGGBB` 字符串。WinForms 可用 `System.Text.Json` 读入 `Dictionary<string, string>`，再用 `System.Drawing.ColorTranslator.FromHtml` 转为画笔和画刷所用的颜色。构建接入时核对正常启动入口可读到打包后的文件。

| 键 | 用途 |
| --- | --- |
| `background`、`floor`、`grid`、`wall` | 窗底、可走地面、淡棋格、实体墙或封闭门 |
| `player`、`friendly`、`enemy` | 红衣唐刀、友方表现或交互提示、敌人主体 |
| `hazard`、`bullet` | 敌方预警边线和纹样、活动敌弹弹芯 |
| `heal`、`ore`、`atmosphere` | 治疗标记、矿石图标、氛围槽 |
| `ink` | 亮面上的深色文字、弹芯外描边、剪影内线 |

【占位】绘制顺序为地面与墙门 → 地面预警 → 角色与敌人 → 活动弹体 → HUD。墙门和地面网格用不同粗细。预警用浅填充或斜纹，保留完整边界。暗底文字用浅色前景。角色一用斜肩斗篷、指向瞄准方向的直背唐刀和短刀穗，冲刺用断续尾迹，小技能用 60° 扇面，大招加绕身棋片和空心盾圈。绘制基于运行时位置、朝向、范围和时钟。图案大小与画面缩放会影响可读性，命中范围跟随玩法配置。

【已定】色板为本项目自制数值，房型、剪影和纹样均可用原生几何绘制，当前交付无第三方图像、音频或字体文件。

## 2. 棋盘与房间

【占位】棋盘预览、小地图和传送面板共用坐标、门边与图例。房型图案居中，探索状态用底形，围住和当前位置用外缘标记。地图仅沿实际门画连接线。

| 对象 | 灰度下的识别标记 |
| --- | --- |
| 普通战斗房 | 单枚棋子，圆 |
| 精英房 | 菱形，内加两道切线 |
| 资源房 | 木梁，三道短横；出生资源房另加角标「起」 |
| 村庄 | 双斜屋顶，图例写「村庄」 |
| 商人 | 有垂边的布幡，图例写「商人」 |
| Boss 房 | 三齿城门，图例写「棋帅」 |
| 未探 / 探索中 / 已完成 | 空心底 / 半填底 / 实心底，必要时反转中心图案明暗 |
| 围住 / 当前房 / 封锁 | 双外框 / 四角括线 / 门缝交叉纹 |
| 可传送路径 | 已完成节点之间的粗线与路径箭头，目标旁显示耗时和可用状态 |

【占位】围住的普通或精英房有可用入口时，面板分别给「自动探索（花费 N 金币，常规奖励）」和「亲自迎战（敌我增强，稀有掉落机会提高）」。围住的 Boss 入口显示「进入 Boss」和围住增益提示。传送正好用完剩余时间时，确认前显示「确认后立即迎战棋帅」。

【占位】资源房用木桩框标建造位。商场用幡与铜钱，建材厂用木梁与齿轮，矿场用矿车与尖晶，村庄用屋顶与灯穗。建造位用虚线框，建成用实线剪影加「1 级」，升级加顶饰和「2 级」，占地和中心保持一致。

## 3. 敌人剪影和预警

| 单位 | 剪影 | 前摇和方向标记 |
| --- | --- | --- |
| 小偷 | 窄肩楔形，单枚短匕首 | 低身向前，短实箭指向直刺 |
| 反贼 | 宽梯形，斜扛宽刀 | 刀影先抬起，长刃与短刺分开 |
| 重盔 | 方肩，高柄圆锤 | 圆砸用实线闭环、中心十字与斜纹，提示敌我均可受击；半圆扫用半盘实边与两条径向边 |
| 骑兵 | 横长马身，前伸长枪 | 刺击用窄枪线，横扫用半圆；冲锋用双侧边宽道和箭头，瞄准可转，锁向后边线加实且方向固定 |
| 弓手 | 兜帽、弧弓和背箭囊 | 瞄准用细虚线与准心，发射后用细箭杆和尖端沿固定方向移动 |
| 镇关棋帅 | 双肩棋纹，宽披风露双臂 | 三招用下表形状；狂暴加锯齿肩纹、一次脉冲与血条旁「狂暴」 |

| 棋帅招式 | 前摇 | 生效和收招 |
| --- | --- | --- |
| 落子·连珠 | 抬掌，窄方向线加连续箭尖，方向锁定时加实 | 高速弹用菱形芯。分发时保留逐发间隔，末发后淡出 |
| 棋盘·环射 | 双虚环加向外短辐条，与重盔的实线闭环加中心十字区分 | 同一时刻由环向外发射圆棋芯。结束时收去辐条 |
| 横斩 | 露刃，朝向明确的宽扇区，外弧带斜纹 | 生效点显示短促刀弧，收招撤掉危险区 |

【占位】范围类预警在前摇结束前显示边界与进度，生效时才显示命中反馈。有锁向的招式按战斗状态更新。横斩以棋帅碰撞体表面和玩法配置核对覆盖。超时入场显示「超时·攻势加剧」，狂暴由血量阶段单独显示。弹量从当前招式快照读取，已起手的招式跨狂暴阈值时按快照完成。

## 4. HUD

| 区域 | 形状与文字 |
| --- | --- |
| 左上生命和盾 | 实心条显示「生命 当前/上限」，独立描边条显示「临时盾 +N」，条长和数值随状态更新 |
| 中上计时和 Boss | 带标签的剩余时间，暂停、预览、Boss 和结算显示「探索停钟」；Boss 名称、独立血条及阶段字样避开主计时和警示 |
| 右上地图 | 复用棋盘图例，当前房四角括线、围住双框，路线旁标耗时 |
| 底部双能量和技能 | 灯穗纹加「氛围值」，交刃纹加「战斗值」，两槽各显示当前/上限；`Q` 两槽满才显示「就绪」，未满提示缺项。冲刺和小技能带按键与冷却数字，开大显示攻增与剩余时间 |
| 右侧资源 | 方孔钱「金币」、木梁「建材」、尖晶「矿石」均附数值；负金币保留负号并标「欠款」 |
| 结算与科技树 | 标题区分胜负，列探索与围住分支、建筑收益、剩余时间；矿石按保存回执显示「已到账」或「尚未入账／重试保存」。科技树标明持久余额和节点锁定原因 |
