# ∞ 回廊 · 参赛玩法重设计

> 2026-11-18｜沿用现有俯视 2D、主题和美术。玩法方案以回廊的岔路、折角和返程为核心，保留人工试玩反馈 B1–B9、M1–M6、N1 的编号。 [项目需求台账](requirements-2026-11-18.md)

## 一、核心玩法 · 绕一圈，从另一侧回击

**脚下走过的回廊，就是这一击的攻击路线。** 从有标记的廊口出发，沿回廊绕行，从另一条廊回到同一处，走过的路线就会按原路逆向扫回一遍。敌人站在哪一段、离玩家有多远、正在向哪条岔路包抄，决定这一次回扫能打中谁。

上一版的关键动作是换门和传送，廊道本身很少被玩家走到。新版让 **廊口负责选路，折角负责断开射线，回到原点负责兑现刚才的走位**。每一段是否走过、先走哪边回来，都直接影响这一击。已有相近的空间玩法，《Loop Hero》用卡牌布置环路地形，《QIX》画线闭合后占领区域。《回廊》这一版要验证的是沿既有通道实时绕行，以及闭环后沿路、按顺序发生的战斗效果。 [Loop Hero 官方商店页](https://store.steampowered.com/app/1282730/Official?l=english) · [QIX 官方作品页](https://www.arcadearchives.com/en/title/aca-198/)

### 第一间房

```text
        ┌── 上廊（短，转角多）──┐
左廊口 ─┼── 中廊（追兵会切入） ─┼─ 右廊口
        └── 下廊（长，有炮台）──┘
```

1. **走出第一圈。** 从左廊口走上廊，在墙角丢开炮台射线，从右廊口走中廊返回。刚进中廊还在追的敌人会先吃到回扫，玩家可以回身补枪。也可以走下廊过去、走中廊回来，多绕一段，把下廊炮台纳入回扫范围。
2. **下一圈换方向或换路。** 同一圈反方向走，波会从另一段先开始。若追兵提前抄进中廊，玩家可以拿冲刺穿过堵点，也可以回退到上个岔口，改走另一条回路。原路退回时擦掉刚走的一段，错过时机可以重新选。普通射击和冲刺继续承担牵制与脱身。
3. **先给两个会改变选路的词条。** 一个让回扫出折角时扩宽，适合上廊。一个在路线达到指定距离时提高回扫伤害，适合经过下廊的长圈。两种路线在同一间房内都能尝试，方便看词条是否真让人换路。
4. **首领沿廊巡行。** 回扫命中巡行中的首领时打破护盾，给玩家短暂输出窗口。二阶段让它更常改走中廊并提前预警。玩家可以赶快完成小圈击中它正在走的路，也可以走长圈覆盖它的备选路线。首领始终在可步行接敌的区域巡行。

### 触发与显示

- 由角色实际经过岔口和廊段来记录路径，绕回起点时自动触发。至少经过两条不同的连接路线，原地转圈和单段来回只更新印记。每个敌人在一次回扫中最多受击一次，上一道波走完后再记下一圈。伤害只结算到波实际经过的通道内。
- 沿用现有键鼠和俯视 2D。用现有颜色画三种地面状态，空白为未走，细线为已走，明亮短波为正在回扫。折角靠墙体碰撞和现有敌弹逻辑表达，教学只需一个高亮廊口和一句「从另一边回来」。
- 房间接缝、所有必打敌人和出口一并做可达性验收。原型采用固定廊段和节点，便于检查哪一段被点亮、回扫从哪儿开始，以及敌人能否被玩家正常接近。 [当前房型与墙体](../src/core/engine.js#L92)

### 从一圈扩到一层

长局沿用**三层、层末存档续玩**。原型先做一间普通房和一场首领战；成立后再用约 4–5 分钟试调一层。每层让玩家至少两次回到熟悉的廊口，第二次换敌人站位或开放一条侧廊，给回来的人一个新选择。词条决定偏好怎样的回路，层末商店让人决定为下一层留钱还是当场补给。

「回廊记得你」也可以变成同一语言。下一局在常走的廊口留下一次路线提示，让玩家主动选熟路或尝试另一圈。实时回扫由规则引擎决定。生成器后续再组合经过验证的廊型、敌人位置和奖励点。 [现有生成逻辑](../src/gen/templates.js#L231)

参赛素材优先录同一间房的两次交战。第一次从上廊出去快速回扫，第二次走下廊把炮台也打到。同一张地图里，玩家的路线选择产生了两种结果。报名提交形态继续按 LifeHack 准备 Qoder Sites 公开试玩地址与天池作品帖。 [赛事公告](https://www.tryan.club/content/e0b6d2e3-1846-4f35-9b84-8ab00b6eac4d?lang=zh) · [现有演示分镜](demo-90s.md)

### M1–M6 · 让这一局的选择影响下一层

| 编号 | 试玩反馈 | 建议与验收 |
|---|---|---|
| **M1 · 初始数值** | 初始血量建议约 40，基础攻速可下调，把攻速做成加成 | 把 **40 HP** 和略慢的攻速做成一套试验配置，连同敌伤、回复和最大生命词条一起调。先比较首层常见失误能承受几次，以及拿到攻速词条后能否感到节奏变化。 |
| **M2 · 长局与存档** | 建议三层、每层约 5 分钟，或层末保存退出 | 先测一层能否形成「拿到核心词条 → 面临一次资源取舍 → 看到选择回报」。正式长局沿用这套循环，通关每层后给继续、保存退出两个出口。续玩从下一层入口恢复已选词条、当前生命、货币和关卡数据，避免刷新后重领结算。 |
| **M3 · 破坏物** | 可破坏墙体与场景物件可掉落道具、金币 | 首批只做木箱和裂墙。木箱产出少量掉落，裂墙打开可选近路或暴露侧翼。两者用不同轮廓或纹理。房间的基础可达性由 B1 保证。 |
| **M4 · 局内金币** | 金币增加不明显，希望掉落、降面值、能在局内花 | 敌人或箱子掉出小面值金币，拾取有音效和计数反馈。先做一个层末商店，提供疗伤、词条重掷两种用途。局内金币与结算后的科技树代币用不同名字和图标。 |
| **M5 · 科技树** | 局外成长应增加选项，特殊效果有限携带，升级节奏放慢 | 首批把科技树做成少量开局选项和互斥的出发配置，例如三选一带入本局。数值类小步升级，递增成本等有真实结算样本后再定。通关后增益、局内增益及后期强节点分批加入。 |
| **M6 · 死亡与奖励箱** | 若使用同一种金币，建议死亡掉落至少 80%；若双币可另行处理；达到指定房间可开奖励箱 | 优先试双币制：局内金币只用于当局消费，科技树代币按进度发放。首次抵达指定房间可开一次奖励箱，提供一个新的开局选项。单币制保留 80% 掉落作为待测方案。 |

### N1 · 主题机制先围绕路怎么走

用试玩提出的旧城案件做一项额外目标，例如「上廊的守卫换班前，从下廊绕回原口，再用回扫击中它」。玩家可以选择是先处理自己面前的追兵，还是冒险走长路完成案件。在主题上保留线索、强敌和案件结算，再根据盲测决定是否让案件改变首领巡行路线。当前先用原有主题和美术搭建玩法房。

## 三、原型怎么验收

1. **第一圈能自己走出来。** 找 6–8 名初次玩家，给一次简短提示，目标是多数人能在第一分钟主动绕回并触发回扫。请玩家指出波先从哪段走，以及为何打中了某个敌人。
2. **第二圈有理由换路。** 普通房先用相同布局，再交换炮台位置或改变追兵起点。观察玩家是否主动反向走、放弃短圈或改选长圈，并说得清当时的理由。若多数人只贴墙射击，或一直跑同一个最短圈，优先改岔路、敌人走位和回扫时机，再扩内容。
3. **绕路不能造成死档。** 分别验证折返回退、反向闭环、重复经过岔口、冲刺跨过触发点和倒地重开。所有必打敌人和出口均可通过实际步行到达。
4. **再扩成首层。** 回扫在一间普通房和一场首领战中成立后，测首层的通关时间、商店取舍、重开和存档恢复。试玩录像同时记录走了哪条路和战斗结果。

> 当前是玩法设计与验收方案。既有俯视 2D 美术沿用，原型手感仍待实测。
