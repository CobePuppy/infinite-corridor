## 0. 先对齐术语：这份文档不是当前代码的直接 bug 清单

文档里至少 6 个核心术语，在我们当前代码库里**并不存在**。若直接照字面改，会改错地方、
甚至把不存在的系统凭空造出来。先做映射：

| 文档说法 | 我们项目实际 | 结论 |
|---|---|---|
| 地图《回环》 | 词表里有房间名「**环室**」；房间 `shape` 枚举为 `arena / corridor / cross / chamber`，**没有「地图」实体** | 疑似指某类房间布局，按刷怪点问题处理 |
| 四地图 | 四套**主题**（几何 / 旧城 / 学科 / 武当），换色板 + 背景 + 词表，不是四张地图 | 术语不同，机制诉求另见 N1 |
| 总局 3 层关卡 | **3–8 个房间 + 1 个首领**，没有「层」 | 术语不同 |
| 局外科技树 | 「局外解锁」：60 金币解锁一个初始词条，无等级 / 代币 / 树 | 文档描述的是另一套成长系统 |
| 房间选项 | 词条二选一 / 每 3 次三选一 | 对应词条卡 |
| 科技树代币 · 奖励箱 · 商店 · 可破坏墙体 · 掉落物 · 局内存档 | **代码里全部不存在** | M3–M6 / N1 属新建系统，不是修 bug |

**判断**：这份文档更像针对另一个版本（或另一款游戏）的试玩反馈。但 B 板块 9 条里
有 **8 条能落到真实缺陷或真实体验问题上**——术语错位不等于诉求无效，所以本轮按「映射到
真实代码」的方式修，不按字面造系统。

## 2. 板块一：底层 Bug（B1–B9）逐条对照

全部结论均**实际去代码里核过**（`src/core/engine.js` / `src/ui/*.js` / `index.html` / `style.css`）。

| # | 文档描述 | 当前代码实况 | 判定 | 本轮修复 |
|---|---|---|---|---|
| **B1** | 刷怪刷到中心、偶尔死档 | `spawnPoint()` 随机取 `x∈[403,826] / y∈[70,530]`（**含画布中心**），40 次重试只查 `hitsWall`；**兜底坐标 `(691,300)` 完全不校验**，可能刷进墙里 | ✅ 真实风险 | `spawnValid()` 统一校验：边界 / 墙体 / 中心禁区 120px / 与玩家最小 170px；随机失败走固定候选点扫描，再走网格兜底，任何返回点都合法 |
| **B2** | 冲刺全局只能用一次、CD 不刷新 | `p.dashCd` 每帧递减，逻辑上能刷新；但 `update()` 开头 `hitstop>0` **直接 return**，密集命中时所有计时器停摆 | ⚠️ 与 B3 **同源** | 定格期间照常递减 `invuln / fireCd / dashCd` |
| **B3** | 受击反馈每颗子弹算一次、过于严重 | `damageEnemy()` 每次命中都写 `hitstop=0.028`（暴击 0.055）+ `shake≥3.5` + 粒子 + 音效；`update()` 命中即早退 | ✅ 确证 | 普通命中**不再定格**、震屏降到 1.6；定格只留给暴击 / 击杀并封顶 0.05 / 0.06；受击（`hurtPlayer`）保留 0.06 重事件定格 |
| **B4** | 部分敌怪 AI 呆在原地 | `static` 分支只置 `vx=vy=0`，**不发弹**；6 处模板用到 `static`，是纯站桩靶子 | ✅ 确证 | 改为**固定炮台**：原地驻守，每 1.5–2.3s 向玩家发一弹，伤害沿用 `e.damage` |
| **B5** | 最上方 UI 遮挡视野 | `.hud` 全宽不透明 `rgba(9,12,20,.82)` + `blur(10px)` + `padding:14px 20px 16px` | ✅ 确证 | 紧凑化 + 半透明渐变 `.62→.22` + `blur(4px)` + `pointer-events:none`（交互控件单独放行） |
| **B6** | 解锁页退出键只在最下面 | `#screen-unlock` 只有底部 `#unlock-back`，24 张卡需滚动到底 | ✅ 确证 | 头部加 `#unlock-close`（×），与底部返回共用 `backFromUnlock()`；Esc 同样可关闭 |
| **B7** | Esc 退出与暂停冲突 | `keydown` 里无条件 `paused = !paused`，在解锁页 / 词条页 / 结算页都会叠加暂停 | ✅ 确证 | 按 `screens.current()` 分流：解锁页→返回、暂停面板→继续、词条页→提示先选、开始/结算页→不叠加、游戏中→切换暂停面板 |
| **B8** | 房间选项下函数名文本 bug | `perkCard()` 渲染 `<div class="perk-id">p_xxx</div>`，卡面露出英文函数 id | ✅ 确证 | 移除该行与对应 CSS 规则 |
| **B9** | Esc 暂停时没有重开选项 | 暂停只有 toast，无面板；且 `begin()` 不重置 `paused`，从暂停态重开会卡住 | ✅ 确证 | 新增 `#screen-pause`（继续 / 重开本局 / 返回开始页）；`begin()` 重建 state 期间冻结、完成后强制 `paused=false` |

**未在本轮处理的 B 项**：无。9 条全部有结论，8 条落地，B2 与 B3 合并为同源修复。
