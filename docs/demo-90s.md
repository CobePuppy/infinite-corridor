## 1. 两局「明显不同」的设计与判据

关卡数据来自 3 套降级模板（3 / 4 / 5 房间各一套），按 `hash(seed)` 轮换；
模板与词条组合随 seed 变化，**录制时通过「再来一局 / R」重开，直到 HUD 房间数出现目标值**
（HUD `room-count` 显示「第 1 / 3 间」「第 1 / 5 间」，是最直观的判据）。

| 维度 | 第一局 | 第二局 | 是否构成差异 |
|---|---|---|---|
| 主题 id / 名称 | `geometry` / 抽象几何 | `oldtown` / 旧城 | ✅ 主题不同 |
| 主题词表示例 | 房间「方庭 / 折廊 / 交集」、敌人 `e_dot`、首领「合点」 | 房间「青砖巷 / 雨棚街 / 拆迁口」、敌人 `o_stray`、首领「巷底影」 | ✅ 文案与命名换一套 |
| 房间数 | **3**（模板 A） | **5**（模板 C） | ✅ 房间数不同 |
| threat 序列 | `1 → 2 → 3` | `1 → 2 → 3 → 4 → 5` | ✅ threat 序列不同 |
| perk_choices 组合 | `[疾步/硬壳] [反刺/回响] [锐眼/凝滞]` | `[疾步/回响] [硬壳/反刺] [锐眼/远击] [凝滞/连锁] [余烬/贪取]` | ✅ 词条组合不同 |
| 首领 | 合点（hp 140 / orbit） | 巷底影（模板 C 的「闭域」按索引重映射，hp 300 / ranged） | ✅ 强度曲线不同 |
| 结算文案语气 | 冷静、几何感 | 潮湿、市井、旧日人烟 | ✅ 主题语气不同 |
| HUD 判据 | 主题标签「抽象几何」+「第 1 / 3 间」 | 主题标签「旧城」+「第 1 / 5 间」 | 镜头可核对 |

> 说明：`perk_choices` 是词条 id，来自固定的 `perk_pool`，**不随主题变化**；
> 两局词条组合的差异来自「模板 A（3 房间）vs 模板 C（5 房间）」，与主题差异相互独立、同时成立。
> 四项差异（主题 / 房间数 / threat 序列 / 词条组合）须**同时**出现在成片里，缺一即不满足 §8 第 7 条。

## 3. §8 要求的记录表：重开率与单局时长

### 3.1 口径定义

- **单局时长**：从 `runStart` 到 `runEnd` 的 `elapsed`（HUD 右上 `timer` / 结算页「存活 x.xs」）。
  目标 **3–5 分钟（180–300s）**；倍速演示片段不计入，本表只登记真实试玩局。
- **结局**：`死亡` 或 `通关`（结算页标题「这次停在了这里」/「走廊走到了尽头」）。
- **是否重开**：该局结束后是否按 `R` / `Enter` 或点「再来一局」立即开始下一局。
- **重开率** = `重开次数 ÷ 总局数`（重开次数 = 表中「是否重开 = 是」的行数；最后一局通常为「否」，不算重开）。
  该指标用于证明「死亡后一键重开」链路可用，无强制阈值，如实登记即可。
- 采样建议：连续试玩 ≥ 5 局，覆盖「死亡」与「通关」两种结局，且至少包含一次切主题重开。
