# ∞ 回廊 · 90 秒演示分镜脚本（高光蒙太奇 v4 · 自由回廊）

> 维护：开发总监（M11 重剪，2026-11-19）｜对应提示词 §8 第 7 条
> 「90 秒演示视频录到两局不同关卡；记录重开率与单局时长」
> 硬截止：**2026/11/30 18:00**（Qoder 高校创造力大赛）

## v4 相对 v3 的改动（如实在案）

v3 按「**回廊长局 · 固定廊道**」主模式撰写：三层九间、四条固定折线廊、
圈型由「走上/中/下哪条廊」决定、相位要求 `any / corner / long / short`。
M11 用户拍板「**替代重做骨架**」后，主模式换成「**自由回廊**」：
圈由玩家真实行走轨迹画出，面积与折点数决定圈型和伤害；固定廊道退居
「经典回廊（旧版可回退）」第二入口。整份分镜的玩法名词再次全部失效，故 v4 整体重剪。

| 项 | v3（回廊长局 · 固定廊道） | v4（自由回廊 · 当前主模式） | 依据 |
|---|---|---|---|
| 单局结构 | 3 层 × 3 间 + 每层巡廊首领，`corridor.loop.save.v1` | **3 层 × 3 间 + 每层巡廊者**，`corridor.free.save.v1`，存档指向下一间 | M11 `core/freewave.js` |
| 圈怎么来 | 沿预设的 2–3 条折线廊绕行 | **按 `E` 自己定起点，沿真实走位画多边形，回到起点才兑现** | `freewave.arm/record/close` |
| 圈型判据 | 走了哪条廊 / 总路程 | **闭多边形面积**（小 / 中 / 大圈）+ 折点数（折角圈），面积过小或点数不足直接拒绝 | `freewave.classify` |
| 主输出 | 闭环回扫（沿廊段） | **沿玩家路径逆行的回扫波**，只结算圈内敌人；子弹 ×0.34 | `freewave.waveFrom` |
| 手感层 | 无 | **斯安维斯坦凝滞**（世界 0.30× / 玩家全速 0.35s）、影子延迟、完美闪避两档增益、连段等级 T1–T3 | `core/chrono.js` |
| 区域层 | 无 | **固定布局的常驻正负地效格**：增幅格（提伤/提速/减 CD）vs 滞涩格（削伤/减速/增承伤） | `freewave.tiles` |
| 构筑 | 独立 `LOOP` 路线池 + 破盾 4 条 | 同池 + **四强化**：顺锋（取消后摇）/ 借势（闪避增益）/ 长锋（扩圈容差）/ 导引（追踪投射物实体，进 `IMPACT` 池） | M11 `perks.js` |
| 首领 | 相位要求 `any → corner → long → short` | 相位要求 **`any → bent → big → small`**（面积档 / 折点），三态强视觉沿用 M9 | `freewave.shieldSpec` |
| 视觉 | 深蓝测绘图 + 兑现光带 + 护盾三态 | 加 **ORIGIN 起点环 / 自由路径 / 地效格 / CHRONO 刻度环 / 完美闪避倒计时环 / COMBO 等级环** | M11 `render.js` |
| 回退 | — | 首页保留「**经典回廊（旧版可回退）**」第二入口，旧 `loop` 分支与 `tests/loop.js 29/29` 原样保留 | M11 |

**不变的三条口径**：

1. **90 秒 = 成片长度**，与单局长度无关；过程全部跳剪，只取爆点。
2. **单局目标 240s ± 30s（210–270s）**，来自用户「单条命通关应该在 4 分钟左右」。
   ⚠️ 该口径针对**真人计时**；**自由回廊三层九间的真人计时尚未做**，
   v4 不把任何自动模拟数字冒充成结论。见 §3。
3. 经典回廊仍可回退，但**演示只录当前主模式**，避免评审混淆两套骨架。

## 1. 两局「明显不同」的设计与判据

§8 只要求「录到两局不同关卡」，**不要求录完整过程**。自由回廊的差异来自
`freewave.create(seed)` 的确定性地格布局、主题切换与**玩家自己选的圈**，不来自「房间数」：

| 维度 | 第一局（建议） | 第二局（建议） | 成片里的交代方式 |
|---|---|---|---|
| 主题 id / 名称 | `geometry` / 抽象几何 | `oldtown` / 旧城 | HUD 主题标签特写 + 四宫格同框 |
| 层 / 间进度 | 第 1 层 第 1 间 | 第 2 层 第 2 间（用「从上次离开的圈接着走」续玩进入） | HUD 层级读数同框特写 |
| 地效格布局 | `seed-A` 的固定正负格分布 | `seed-B` 的另一套分布 | 地面 `BOOST / SLOW` 格特写 |
| 玩家圈的判据 | **大圈**（矩形大绕，面积 ≥ 110000） | **折角小圈**（贴着掩体绕出多个折点） | 兑现读数的「大圈 / 中圈·折角」特写 |
| 首领相位圈型 | 相位 1「任意闭环」→ 相位 2「折角圈」 | 相位 2「折角圈」→ 相位 3「大圈」 | 护盾条相位标签同框 |
| 四强化组合 | 导引（追踪弹）+ 长锋（扩圈） | 顺锋（取消后摇）+ 借势（完美闪避） | 第 3 段词条卡特写 |
| 结局 | 通关或死亡 | 另一结局（两种都要覆盖） | 结算页 |

> **四项硬差异**（主题 / 层间进度 / 圈型与地效 / 四强化组合）须在成片中**可辨认**，
> 用 HUD 特写同框 + 数据卡即可满足 §8 第 7 条，不录完整过程。
> 同一 seed 的地格布局可复现；录制时用新 seed 或续玩存档取到不同层间。

## 3. §8 要求的记录表：重开率与单局时长

### 3.1 口径定义（v4 修订）

- **单局时长**：从 `runStart` 到 `runEnd` 的 `elapsed`（结算页「存活 x.xs」）。
  目标 **240s ± 30s，即 210–270s**；倍速 / 跳剪演示片段**不计入**，本表只登记真实试玩局。
- **主模式口径**：一次「局」= 从首页「自由回廊」开局，到通关第 3 层或死亡；
  「从上次离开的圈接着走」续玩属于**同一局**，不另计一局。
- **结局**：`死亡` 或 `通关`（结算页标题「这次停在了这里」/「走廊走到了尽头」）。
- **是否重开**：该局结束后是否点「再来一局」立即开始下一局。
- **重开率** = `重开次数 ÷ 总局数`（最后一局通常为「否」，不算重开）。无强制阈值，如实登记。
- 采样建议：连续试玩 ≥ 5 局，覆盖「死亡」与「通关」、至少一次切主题重开，
  **且至少覆盖第 1 层与第 2 层**（续玩链路要在样本里出现）。

### 3.4 为什么 v4 仍不放理论外推表（如实说明）

v2 §3.4 曾用 `calibrate()` 按「敌人 HP ÷ 子弹 DPS × 命中率」外推房数时长。
**这个模型对当前主模式更不成立**：自由回廊的主输出是玩家自己画出的多边形回扫
（面积分档伤害 24 / 30 / 52，连扫最高 ×1.32，护盾窗口 ×2.2），子弹被压到 ×0.34；
还叠加凝滞（世界 0.30×）、地效增益、完美闪避增伤与取消后摇。
**路径面积、折点数、踩到哪一格、相位要求的圈型**才是时长变量，没有可信的闭式解。

因此 v4 **不放一张看似精确、实则失真的外推表**。4 分钟是否达成，以 §3.2 真人计时为准；
若真人实测偏长，校准旋钮集中在 `src/core/perks.js` 的
`BALANCE.free`（`damage*` / `areaMid` / `areaBig` / `minArea` / `shield.baseNeed` /
`shield.baseWindow` / `mod.*`）与 `BALANCE.chrono`，**不得直接改 `engine.js` 的手感常量**。

> 自动化脚本只能证明链路成立、基线未回归，**不能**代替手感与时长采样，故 §3.2 留空待录。
